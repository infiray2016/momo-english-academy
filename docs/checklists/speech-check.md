# 음성 점검표(H2)

- 목적: 9절 '음성 점검' 행 · 11절 1-가 첫 작업(iPad Safari 실기 확인) · AC-N3(마이크를 쓸 수 없는 기기)의 P2 몫. 근거 plan `intent/2026-10-15-모모-잉글리시-아카데미/plan-p02-음성-접점.md` 값 10 · 정할 것 가-5(C53 (5)).
- 관찰 페이지 주소: (H1 뒤 적음) `https://<프리뷰 배포>/dev/speech-probe` — 프리뷰 배포에만 있고 Vercel Authentication 으로 가려진다. 운영 배포에는 없다.
- 하는 사람: 어른이 관찰 페이지의 시험 문장을 읽는다. Chrome(과 Edge)은 소리를 인식 서버로 보낸다. 사람 이름을 말하지 않는다. 소리는 저장하지 않는다.
- 기기마다 끝나면 관찰 페이지 '7. 기록'의 '대본으로 내보내기'로 .json 을 내려받아 장부로 보낸다(`tests/fixtures/speech/recorded/<기기>-<날짜>.json`, plan P2b 작업 8). 내보내기는 끝까지 들은 듣기(끊김 제외)만 start() 순서대로 담고, 마이크 확인의 인식 객체는 넣지 않는다.
