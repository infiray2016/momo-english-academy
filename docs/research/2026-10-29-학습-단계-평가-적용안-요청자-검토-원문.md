## 2. R-1 — 현재 12단계는 유지하되 CEFR-J 대응 방식은 바꾸는 게 좋겠습니다

분석가의 (다-ㄱ) 제안은 개발 비용을 고려하면 합리적입니다. 이미 48개 레벨 규격, 242개 단원 규격, 1,920개 어휘 데이터가 마련되어 있으니까요.

다만 48개 영역별 단계에 CEFR-J 레벨 이름을 붙이는 작업은 주의해야 합니다.

| 앱 단계 | 현재 자체 구간 | 공식 CEFR-J와의 관계 |
|---|---|---|
| 1~3 | Pre-A1 | Pre-A1과 A1의 일부 과제가 섞일 수 있음 |
| 4~6 | A1 | A1.1~A1.3 일부와 비교 가능 |
| 7~9 | A2 | A2.1~A2.2 일부와 비교 가능 |
| 10~12 | B1 | B1.1~B1.2 일부와 비교 가능 |

이 표는 정식 대응표가 아니라 비교를 위한 구조 설명입니다.

문제는 앱 3단계의 읽기 과제는 CEFR-J A1.3에 가까운데, 같은 3단계의 회화 과제는 Pre-A1에 가까울 수도 있다는 거예요. 즉, 레벨 숫자나 영역만 보고 CEFR-J 이름 하나를 자동 배정하면 안 됩니다.

권장 구조: 앱의 공식 진도 체계(예: Reading · Level 2 — 자체 12단계 중 2단계) · 실제 학습 목표(그림과 함께 제시된 짧은 영어 문장을 읽고 필요한 정보를 찾는다) · CEFR-J 참고 자료(관련 Can-do 수준 A1.1~A1.2 예시 — 실제 과제 대조와 검토를 거쳐 확정할 예시이며 공식 매핑 아님).

저는 단계 → CEFR-J 레벨보다는 **학습 과제 → 관련 Can-do 기술문**의 관계를 우선 만들겠습니다. 그리고 48개 단계 행에는 해당 과제들을 종합한 참고 범위를 표시하는 거죠. 공식 CEFR-J 기술문은 학습자가 수행할 수 있는 실제 활동을 설명하는 방식이므로, 과제를 먼저 비교하는 편이 더 타당합니다. Musubu Communication

또 하나, 분석가가 걱정한 버전 문제는 일부 확인됐습니다. CEFR-J Can Do List Version 1.3, 2025년 3월 25일자 영문판은 실제로 공개되어 있습니다. 2025 CEFR-J 심포지엄 자료라는 출처 정보도 확인됩니다. 따라서 무조건 1.0만 사용할 필요는 없습니다. 다만 1.0과 1.3의 기술문 및 식별 방법을 대조한 후 한 버전으로 고정해야 합니다. Musubu Communication +1

## 3. R-2 — 초등학교 4학년은 2단계로 시작하는 데 동의합니다

단, 이것은 시작 추천 단계이지 실제 영어 실력에 대한 판정이 되어서는 안 됩니다.

2022 개정 영어 교육과정에서 초등학교 3~4학년군의 학습 어휘는 300개 이내입니다. 하지만 이 수치는 수업에서 다루는 어휘의 범위이지, 학생이 실제로 알고 사용할 수 있는 단어 수를 의미하지는 않습니다. goe.go.kr +1

따라서 앱의 2단계 어휘 누계가 250개라는 이유만으로 초4의 실제 수준을 2단계로 단정할 수는 없습니다.

저라면 이렇게 운영하겠습니다.
- 초4 기본 추천: 앱 2단계
- 영어를 처음 시작하는 아이: 1단계 선택 가능
- 영어 학습 경험이 많은 아이: 배치 평가 또는 보호자 설정으로 조정
- 처음 몇 수업에서는 실제 수행을 관찰해 난이도 조절

배치 평가가 3단계부터 시작하는 기존 구조도 일단 유지할 수 있습니다. 다만 1~2단계 학생을 구별하는 역할까지 하는지는 별도로 검증해야 합니다.

## 4. R-3 — 수행 근거 계산은 동의하지만, 현재 기준에 문제 세 가지가 있습니다

여기가 이번 문서에서 가장 크게 수정할 부분입니다.

문제 A. 단어를 말한 것만으로 독립 수행이라고 할 수 없습니다. 현재 제안은 회화에서 said_words를 독립 수행의 근거로 사용합니다. 예를 들어 "What is it?" + 사과 그림 → "Apple." / "Do you like apples?" → "Yes, apples." / "Apple or banana?" → "Apple." 세 상황 모두 영어 힌트나 정답 노출 조건이 다릅니다. 두 번째는 질문 속에 목표 단어가 있고, 세 번째는 선택지로 정답 후보를 들려준 상황입니다. 따라서 said_words는 어휘 사용 기록으로 유지하되, 독립적인 수행 여부는 과제 조건과 도움 여부를 함께 확인해야 합니다.

문제 B. 서로 다른 수업에서 두 번 말했다고 '응용 성공'은 아닙니다. 현재 3.7절의 "3 응용 = 서로 다른 수업에서 2번 독립 수행"은 수정하는 게 좋겠습니다. 같은 사과 그림을 이틀 동안 맞힘 → 반복 성공 · 유지 근거. 다른 사과 그림을 보고 맞힘 → 새로운 예시에서 재인식. 사과를 달라고 하는 상황에서 표현 사용 → 다른 의사소통 상황에 응용. 반복 성공과 새로운 상황에 응용하는 것은 다른 능력입니다. 3 응용은 날짜나 수업이 다르다는 이유로 자동 부여하지 않고, 과제의 맥락이 실제로 달라졌는지 확인해야 합니다.

문제 C. 가장 높은 근거만 남기면 현재 상태가 왜곡됩니다. 3주 전에 독립 수행에 성공했지만 최근 복습에서는 계속 어려워한다면, 최고 근거만 계산하면 계속 2 독립 수행 상태로 남습니다. 그래서 최고 수행 근거(과거에 어디까지 할 수 있었는가) · 최근 수행 근거(현재도 할 수 있는가) · 복습 필요 여부(다음 학습에서 무엇을 다시 연습할까)를 분리하는 것이 좋겠습니다. 새 테이블이 꼭 필요하지는 않습니다. 기존 attempts, talk_turns, sessions에서 계산할 수도 있습니다. 다만 계산에 필요한 과제 유형, 힌트, 유효성, 맥락 정보는 기록되어 있어야 합니다.

제안: R-3은 첫 버전에서 평가 근거를 누적하고 기존 판정과 비교하는 병행 검증 방식으로 진행하되, 향후 단원 통과·복습 기준에 반영할 수 있도록 설계하세요.

## 5. R-4 — 근거가 부족하면 판정을 미루는 것이 맞습니다

이 결정은 분석가의 (나)에 동의합니다. 특히 현재 단계 평가가 20문항, 16점 통과 구조라면 유효하게 채점한 문항이 너무 적은데도 높은 정답률만으로 승급하는 상황을 막아야 합니다.

| 평가 결과 | 판단 |
|---|---|
| 20문항 채점, 17개 정답 | 정상 판정 가능 |
| 20문항 중 8개만 채점, 8개 정답 | 승급 보류 |
| 20문항 중 17개 채점, 한 단원 문항만 전부 누락 | 해당 단원 평가 보완 필요 |
| 음성 인식 오류로 말하기 평가 실패 | 재시도 또는 판정 보류 |

단순히 '절반 이상 채점했으면 된다'는 기준보다는 전체 평가 근거의 양과 핵심 단원별 평가 범위를 함께 확인해야 합니다. 가능하면 채점에 실패한 문항을 재시도하거나 동등한 대체 문항을 제공하고, 그래도 근거가 모자랄 때 U(보류)로 처리하는 것이 좋겠습니다. 여기서 U는 실패가 아닙니다. 판단할 만큼 충분한 정보를 확보하지 못했다는 의미입니다.

## 6. 한 가지 더 추가하고 싶은 개선

현재 적용안은 48개 단계별 Can-do를 참고로 관리하지만, 실제 단원의 학습 목표는 lesson_id → unit_specs를 통해 찾도록 되어 있습니다. 저는 이것만으로 충분한지 확인하고 싶습니다. 예를 들어 농장 수업의 목표가 "Level 1 · 농장 친구와 대화하기 — 학습 콘텐츠 name, apple, egg, banana, milk / 학습 요소 사물 이름, 간단한 인사, 이름 표현 / Can-do 목표 그림을 보고 익숙한 사물 이름을 말하며 간단한 질문에 응답할 수 있다"라면, 단어 다섯 개를 말했다고 Can-do 목표 전체가 달성되는 건 아닙니다. 학생이 질문을 이해하고 적절하게 응답했는지까지 확인해야 하니까요. 따라서 최소한 단원 목표의 고유 ID와 실제 평가 과제를 연결하는 구조는 필요합니다. 별도 DB 테이블을 만드는 대신 기존 시드에 목표 ID를 추가하는 방법도 가능합니다. 이 부분은 읽기·쓰기·말하기·회화 네 영역 모두에 동일하게 적용됩니다.

## 8. 최종 결정안

- R-1 · 단계 체계: 다-ㄱ. 기존 12단계를 유지합니다. 다만 공식 CEFR-J 12단계와 혼동하지 않도록 자체 레벨임을 명시하고, 각 평가 과제와 CEFR-J Can-do의 관계를 참고 자료로 관리합니다.
- R-2 · 초등 4학년 시작 단계: 가. 기본 추천 2단계를 유지합니다. 학년만으로 수준을 확정하지 않고, 보호자 설정 및 배치 평가로 조절합니다.
- R-3 · 수행 근거: 가 수정. 기존 데이터를 바탕으로 0·1·2·3·U를 계산하되, 독립 수행·반복 성공·새로운 상황의 응용을 구분합니다. 초기에는 기존 평가와 병행 검증하고, 검증 후 단원 통과와 복습 로직에 반영합니다.
- R-4 · 근거 부족 시 판정: 나 보완. 근거 부족 시 판정을 보류합니다. 최소 채점 문항 수뿐 아니라 단원별 평가 범위까지 확인하고, 채점 실패는 재시도 또는 대체 문항으로 보완합니다.

## 제 결론

현재 앱의 자체 12단계 체계를 유지하는 선택은 개발 비용과 기존 설계의 일관성 면에서 타당합니다. 다만 이전 대화에서 제가 이 12단계를 공식 CEFR-J 12단계라고 이해한 부분은 정정해야겠습니다.

지금 분석가의 접근은 기존 시스템을 최소한으로 변경하면서 새로운 평가 요구를 반영하는 것에 상당히 집중되어 있어요. 개발 측면에서는 좋은 접근이지만, 영어 선생님 앱에서 더 중요한 것은 평가가 실제 언어 능력을 얼마나 정확하게 반영하느냐입니다. 그래서 저는 기존 평가 로직을 당장 갈아엎지는 않더라도, 수행 근거를 형식적으로 계산만 하는 기능으로 끝내지 않는 것을 권합니다. 이렇게 하면 기존 구현을 보존하면서도 장기적으로는 읽기·쓰기·말하기·회화 각각에서 학생이 실제로 할 수 있는 것이 무엇인지 판단하는 학습 앱으로 발전시킬 수 있습니다.
