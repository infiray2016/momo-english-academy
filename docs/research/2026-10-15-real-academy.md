# 리얼 아카데미 조사

조사일 2026-10-15. 요청자가 설계에 참고하라고 지목한 서비스다. 공식 사이트는 자동 접근을 막아 후기 다섯 건과 기사 세 건을 근거로 정리했다.

## 1. 개요

뤼이드(Riiid)가 2024년 9월 시작하고 12월에 정식 출시한 초등 영어 서비스다. 인수한 퀄슨의 리얼클래스 콘텐츠와 뤼이드의 AI 진단 기술을 합쳤다. 구호는 "집에서 다니는 대치동 영어학원", "1일 1아웃풋 초등영어"다. 2028학년도 대입이 논 · 서술형 중심으로 바뀌는 것을 근거로 말하기 · 쓰기(아웃풋)에 집중한다. 전용 패드, 키보드, 거치대, 학습 노트, 영작 교재 21권이 함께 온다. 가격은 후기 기준 월 89,000원에 24개월 약정이다. 2025년 2월 거래액 약 6억 원.

## 2. 구성 요소

| 요소 | 내용 |
|---|---|
| GV 레슨 | 핵심 활동. G 는 문법, V 는 어휘. 매일 바뀌는 '오늘의 주제'로 AI 튜터 리아(LIA) 또는 AI 캐릭터 에코와 대화한다. 한국어와 영어를 섞어 써도 된다. 대화하며 아이의 생각을 끌어내 문장 3줄을 만들고, 아이가 한글로 타이핑해 제출하면 첨삭이 오고, 첨삭된 문장을 영어로 옮겨 쓴다. 처음 쓴 문장과 고친 문장을 나란히 보여 준다. Sentence Builder 로 문장 구조를 놀이처럼 익히고, 자기가 만든 문장을 쓰기와 말하기로 반복한다 |
| GV 맵 | 레벨 테스트(10분, 12문제, 영문 타자 입력, 즉시 결과)로 수준을 진단하고 맞춤 학습 경로를 준다. 문장 부호까지 채점한다. 결과지에 오답, 미국 학년 환산, 중학교 수행평가 예상 점수, 영역별 강점과 보강점이 나온다. 학습한 문법 패턴과 단어, 누적 학습량, 취약점을 한눈에 보여 준다(필수 문법 1천 개, 어휘 3천 개) |
| GV 블록 | 문법과 단어를 블록 단위로 나눠 배운다 |
| 다이어리 | 대화로 주제를 끌어내 영작 일기를 쓰고, 내용에 맞는 그림을 자동 생성한다 |
| 라이브 클래스 | 주 5일 실시간 수업. 대치동 강사와 원어민. 시간표에서 골라 참여하고 음성과 키보드로 답한다 |
| 라이브 퀴즈 | 월~목 저녁 8시. OX, 문장 순서 맞추기(unscramble), 문법, 쓰기 12문제를 100명 이상이 동시에 풀고 순위를 매긴다. 후기에서 대문자 · 마침표 실수로 점수를 잃은 아이가 스스로 습관을 고쳤다고 한다 |
| 영어 애니 섀도잉 | 애니메이션을 보다가 중간중간 따라 말한다. 900시간 분량 스크립트 |
| 오늘의 단어 학습 | 단어 학습 활동 |
| 타자 연습 게임 | 영문 자판 연습. 레벨 테스트에서 영문 타자가 느려 애먹었다는 후기가 있다 |
| AI 또래 친구 | AI 로 만든 외국 또래와 대화한다 |
| 홈 | '오늘의 추천 학습'을 퀘스트처럼 나열한다. 학습량을 아이 또는 부모가 설정한다 |
| 보상 | 별코인. 30개를 모으면 편의점 · 다이소 기프티콘을 고르고, 마켓데이에 아바타를 꾸민다 |
| 교재 | 영작 교재 21권 배송. 초등 필수 영단어와 영어 패턴. 온라인에서 배운 것을 손글씨로 복습 |
| 학부모 리포트 | 학습 내용을 부모에게 보고한다 |

후기에서 반복되는 평가는 세 가지다. 대화로 생각을 끌어내서 아이가 자기 문장을 만든다는 점, 틀린 것을 스스로 확인하는 경험이 설명보다 효과적이라는 점, 보상과 순위가 매일 하게 만든다는 점이다. 약점으로는 가격과 약정, 영문 타자 부담이 보인다.

## 3. 우리 설계와 비교

| 리얼 아카데미 요소 | 모모 잉글리시 아카데미 | 반영 |
|---|---|---|
| 대화로 생각을 끌어내 영작 | 6단계부터 쓰기 세션 앞에 '생각 꺼내기' 대화를 둔다. AI 가 한국어로 2~3개 질문하고 아이의 답을 영어로 옮기는 과제로 잇는다 | 반영 |
| 처음 쓴 문장과 고친 문장 비교, 내 문장으로 말하기 | 첨삭 화면에 이미 있다. 4단계부터 세션 끝에 '내 문장 듣고 따라 말하기'를 붙인다 | 반영 |
| Sentence Builder, 문장 순서 맞추기 | 쓰기 3단계 단어 카드 조립과 같다. 대문자 · 마침표 카드를 둔다 | 이미 있음 |
| 1일 1아웃풋 | 그날 만든 문장 하나를 '오늘의 한 문장'으로 홈에 붙인다 | 반영 |
| GV 맵(진단 결과, 학습 지도, 취약점) | 배치 · 단계 평가 결과 화면에 영역별 점수 · 오답 · 추천 단계를 보여 주고, 부모 화면에 학습 지도(문법 요소 · 어휘 누적 · 취약점)를 둔다 | 반영 |
| 보상(코인 → 실물, 아바타) | 별로 아바타를 꾸미고, 부모가 실물 보상을 등록해 홈에 목표로 보인다 | 반영 |
| 타자 연습 | 쓰기 2단계 받아쓰기를 화면 자판으로 하고, 3차에 타자 게임을 넣는다 | 반영 |
| 교재, 손글씨 복습 | 단원 데이터로 연습지 PDF 를 만들어 부모 화면에서 내려받는다(3차) | 반영 |
| 학부모 리포트 | 부모 화면에 '이번 주 요약'을 둔다 | 반영 |
| 영작 일기 그림 자동 생성 | 7단계 일기 과제에 선택 기능으로 검토(3차) | 보류 |
| 라이브 클래스, 라이브 퀴즈, 원어민 | 사람 교사가 없다. 역할극이 대화 연습을 일부 대신한다 | 넣지 않음 |
| 애니 섀도잉 | 저작권 있는 영상을 쓸 수 없다. 따라 말하기는 생성한 문장과 읽어 주기로 한다 | 넣지 않음 |
| 전용 패드 · 키보드 | 가정의 태블릿과 PC 를 쓴다 | 넣지 않음 |
