## 1. 선생님 TTS 음성 개선

### ① 적용 범위: 다 선택

영어 선생님 음성뿐 아니라 다음 전체 영역을 개선 대상으로 합니다.

- 회화 중 선생님의 영어 대사
- 선생님의 한국어 설명 및 안내
- 읽기 지문 읽어 주기
- 듣기 대본 및 말하기 학습 음성
- 배치 평가·단계 평가의 듣기 문항

단, 평가에서 음성 제공 여부, 재생 횟수, 도움 기록 등 기존 평가 규칙은 변경하지 않습니다.

### ② TTS 방식: iOS 기본 음성 우선

**외부 AI TTS 제공자 및 모델 선정은 추후 결정합니다.**

지금은 기존 Web Speech API 기반 음성 품질을 개선합니다.

- iOS·iPadOS에서는 Siri처럼 자연스러운 Apple 음성을 우선 사용합니다.
- Safari에서 실제 Siri 음성을 직접 사용할 수 있는지 확인합니다.
- Siri 음성을 직접 선택할 수 없다면 `speechSynthesis.getVoices()`에 노출되는 Apple 음성 중 가장 자연스러운 고품질 음성을 기본으로 선택합니다.
- 영어와 한국어는 각 언어에 맞는 음성을 사용합니다.
- 미나와 리오는 가능하면 서로 다른 고품질 음성을 사용합니다.
- 현재처럼 동일한 음성의 pitch만 변경하여 캐릭터를 구분하는 방식은 개선합니다.
- 사용 가능한 음성이 없는 경우 기존 기본 TTS로 Fallback합니다.
- 특정 음성 이름을 코드에 무조건 고정하지 말고 실제 기기에서 제공하는 목록을 기준으로 선택합니다.
- iPad Safari에서 실제 음색과 발음, 영어·한국어 전환의 자연스러움을 확인합니다.

**외부 AI TTS 도입은 별도 변경 단위로 유지하되, 제공자 비교·선정과 실제 적용은 보류합니다.**

현재 진행 중인 회화 첫 프리뷰에 외부 TTS 도입을 필수 조건으로 추가하지 않습니다.

### ③ 비용: 기존 알림 체계 유지

- 기존 AI 호출 비용 알림 기준인 하루 $1 / 월 $12를 유지합니다.
- 향후 외부 AI TTS를 적용하면 TTS 비용도 통합 집계합니다.
- 가능하면 Claude API 비용과 TTS 비용을 구분해 확인할 수 있도록 합니다.
- 비용 알림 때문에 아이의 진행 중인 수업을 중단하지 않습니다.
- 현재 iOS 기본 음성 개선에는 별도의 외부 TTS API 비용이 발생하지 않도록 합니다.

### ④ 지연 및 Fallback

- 향후 AI TTS 적용 시 기존 음성 대비 추가 첫 소리 지연은 1초 이내를 성능 목표로 합니다.
- 1초 초과만으로 즉시 기기 TTS로 전환하지 않습니다.
- 실제 오류나 별도 타임아웃 조건에서만 Fallback합니다.
- 한 발화 도중 음성이 갑자기 바뀌지 않도록 합니다.
- 현재 Web Speech API 개선에서도 재생 중단, 다시 듣기, 아이의 끼어들기, 감시 타이머, 기술 오류 복구 규칙은 유지합니다.

### ⑤ 적용 시점

- iOS·iPadOS 기본 음성 선택 개선은 현재 회화 구현 과정에서 기존 구조를 변경하지 않는 범위로 우선 반영합니다.
- 외부 AI TTS의 목소리 표본 비교 및 제공자 선정은 추후 별도로 진행합니다.
- 외부 AI TTS 실제 구현은 회화 첫 프리뷰 이후 판단합니다.
