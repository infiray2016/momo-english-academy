# 모모 잉글리시 아카데미 설계

작성일 2026-10-15. 상태는 요청자 검토 대기.

## 1. 목적과 범위

초등 4학년부터 쓸 수 있는 영어 학습 웹 앱이다. 읽기 · 쓰기 · 말하기를 독립된 트랙으로 두고, 트랙마다 12단계를 CEFR Pre-A1 에서 B1 까지 대응시킨다. 수업 내용은 AI 가 단계 규격에 맞춰 생성하고, 첨삭과 평가도 AI 가 맡는다. 사용자는 한 가정의 아이 1명에서 시작해 2~3명까지 늘어난다.

| 구분 | 내용 |
|---|---|
| 포함 | 세 트랙의 세션, 단계 · 유닛 · 승급, 어휘 복습, 단계 평가 · 배치 평가, 부모 화면, 프로필 2~3개 |
| 제외 | 회원 가입과 결제, 여러 가정을 동시에 받는 서비스, 네이티브 앱, 발음 정밀 채점 전용 서비스(교체 접점만 둔다) |

## 2. 사용자와 성공 기준

| 사용자 | 하는 일 | 환경 |
|---|---|---|
| 아이 | 홈에서 트랙을 골라 5~8분 세션을 끝까지 한다. 하루 세 트랙을 다 하면 20분 안팎이다 | 집, 태블릿 또는 PC, Chrome 또는 Safari(Web Speech API 음성 인식 지원 브라우저) |
| 부모 | 진도 확인, 단계 · 유닛 조정, 설정값 변경, 다음 유닛 수업 미리보기, AI 사용량 확인 | 같은 기기 또는 PC, PIN 으로 진입 |

성공 기준은 세 가지다. 아이가 부모 도움 없이 세션을 끝까지 마친다. 단계가 오르면 실제로 더 긴 글을 읽고 쓰고 말한다. 부모가 손대지 않아도 2~3주 분량의 수업이 항상 준비되어 있다.

## 3. 학습 설계

### 3.1 트랙과 단계

세 트랙은 서로 독립이다. 단계 · 유닛 · 연속 학습 일수 · 승급이 모두 트랙마다 따로 돌아간다. 공유하는 것은 단어장 하나뿐이다.

| 앱 단계 | CEFR | 대략적인 학교 수준 |
|---|---|---|
| 1~3 | Pre-A1 | 초4~5 |
| 4~6 | A1 | 초6~중1 |
| 7~9 | A2 | 중2~3 |
| 10~12 | B1 | 중3~고1 |

트랙 × 단계 36개마다 can-do 문장을 둔다. 이 문장이 수업 생성과 평가의 기준이 된다. 읽기 4단계의 예는 "일상 주제의 100단어 안팎 짧은 글을 읽고 사실 관계 질문에 답할 수 있다"이다. 36개 문장과 유닛 규격 180개의 초안은 구현 계획의 첫 작업으로 만든다(요청자 결정 2026-10-15).

### 3.2 유닛과 승급

| 단위 | 구성 | 분량 |
|---|---|---|
| 유닛 | 문법 요소 1개 + 주제 어휘 30개 안팎 | 수업 8~10회, 최소 6회 |
| 단계 | 유닛 5개 | 수업 40~50회, 매일 하면 두 달 안팎 |
| 트랙 | 12단계 | 약 540회 |

승급은 수업 횟수가 아니라 숙달 정도로 판단한다.

| 판정 | 조건 | 못 미칠 때 |
|---|---|---|
| 유닛 통과 | 유닛 어휘의 80% 이상이 단어장에서 "안다" 상태(서로 다른 날의 복습에서 3회 연속 정답)이고, 최근 수업 5회의 과제 성적 평균이 80% 이상 | 약한 어휘 · 문법을 다루는 보강 수업을 생성해 계속 진행한다 |
| 단계 승급 | 유닛 5개를 모두 통과한 뒤 열리는 단계 평가(어휘 · 문법 · 영역 과제 20문항)에서 80% 이상 | 틀린 문항과 연결된 유닛의 보강 수업을 받은 뒤 다시 본다 |

과제 성적의 뜻은 트랙마다 다르다. 읽기는 이해 문제 정답률, 쓰기는 5단계까지 정답률이고 6단계부터 과제 충족 · 문법 · 어휘 루브릭 점수, 말하기는 목표 문장 일치율과 답변 적절성이다.

첫 실행 때 트랙별 배치 평가를 보아 시작 단계를 정한다. 배치 평가 문항은 트랙별 고정본이다. 부모는 부모 화면에서 단계와 유닛을 직접 조정할 수 있고, 자동 승급과 유닛 통과는 모두 기록을 남긴다.

시간 총량은 트랙당 약 60시간, 세 트랙 합계 약 190시간이다. 통상 CEFR 추정 학습 시간(A1 약 100시간, A2 누적 약 200시간, B1 누적 약 350~400시간)보다 적으므로, B1 은 학교 수업과 합쳐서 도달하는 목표로 본다. 분량은 설정값(유닛당 수업 횟수, 세션 길이)으로 늘릴 수 있다.

### 3.3 트랙별 세션과 사다리

읽기 세션은 새 단어 미리보기 → 지문 읽기(읽어 주기 제공, 단어를 누르면 뜻) → 객관식 이해 문제 → 틀린 문제 해설 순서다.

| 단계 | 지문 길이 | 글 종류 | 문제 |
|---|---|---|---|
| 1 | 단어와 짧은 문장 1~3개 | 그림과 짝지은 단어 · 문장 | 그림 고르기 3문제 |
| 2 | 3~5문장 | 그림이 있는 짧은 글 | 사실 확인 3문제 |
| 3~4 | 50~90단어 | 일상 이야기, 그림 설명 | 사실 확인(누가 · 무엇 · 어디) 3문제 |
| 5~8 | 100~180단어 | 이야기, 편지, 설명문 | 사실 확인 + 추론 1문제, 총 4문제 |
| 9~12 | 200~300단어 | 설명문, 기사, 짧은 에세이 | 주제 찾기, 추론, 문맥으로 뜻 추측, 총 5문제 |

쓰기 세션의 순서는 단계에 따라 다르다. 초반에는 아이가 문장을 만들어 내지 않고 알아보고, 베끼고, 조립만 한다(요청자 결정 2026-10-15). 문법은 설명하지 않고 단어 카드를 순서대로 놓는 일로 익힌다. 초3~4 교육과정의 쓰기 성취기준이 낱말 따라 쓰기까지이고, 예시문을 보고 간단한 문장을 쓰는 것은 초5~6 이기 때문이다.

| 단계 | 세션 순서 | 피드백 |
|---|---|---|
| 1~3 | 과제 → 고르기 · 베끼기 · 조립 → 확인 | 정답 비교. 틀리면 정답을 보여 주고 다시 한다. AI 없음 |
| 4~5 | 과제 → 쓰기 → 확인 → 내 문장 듣고 따라 말하기(선택) | 같은 화면에 문장마다 표시. 칭찬 한 줄, 고칠 곳 최대 1개를 말풍선으로 보여 주고 버튼 한 번으로 고친다. 모범 답안 없음 |
| 6~12 | 과제 → 생각 꺼내기 → 쓰기 → 첨삭 → 고쳐 쓰기 1회 → 내 문장 말하기 | 생각 꺼내기는 AI 가 한국어로 2~3개 질문하고 아이가 한국어 · 영어를 섞어 답하는 짧은 대화다. 거기서 나온 아이의 생각을 영어로 옮기는 것이 쓰기 과제가 된다. 첨삭은 칭찬 1개, 교정 최대 2개(원문 · 수정 · 이유), 모범 답안, 루브릭 점수 |

| 단계 | CEFR | 과제 | 문법 초점 |
|---|---|---|---|
| 1 | Pre-A1 | 그림 보고 단어 고르기, 단어 베껴 쓰기, 빠진 글자 채우기(b_ll → ball) | 없음 |
| 2 | Pre-A1 | 듣고 단어 받아쓰기(화면 자판으로 영문 자판도 익힘), 철자 타일로 단어 만들기, 두 단어 어구 조립(a red apple) | 없음(어순만) |
| 3 | Pre-A1 | 섞인 단어 카드를 순서대로 놓아 문장 만들기(dogs / I / like → I like dogs.) | 어순, 대문자 · 마침표 |
| 4 | A1 | 문장 틀 + 단어 상자로 3문장 완성 | be 동사, 현재시제 |
| 5 | A1 | 예시문을 보고 단어만 바꿔 3~4문장 쓰기 | 단수 · 복수, 현재시제 |
| 6 | A1 | 주제만 주고 4~5문장 자유 작문 | 현재시제, 3인칭 단수 s, 관사 |
| 7~9 | A2 | 한 문단 6~8문장. 일기, 편지, 하루 설명 | 과거 · 미래시제, and · but · because |
| 10~12 | B1 | 100~150단어. 의견과 이유, 비교, 설명 | 서론-본문-결론, 관계대명사, 접속부사 |

말하기 세션은 듣고 따라 말하기 → 질문에 답하기 → (5단계부터) AI 가 상대역을 맡는 역할극 3~4턴 순서다. 음성은 브라우저가 글자로 바꾼다.

| 단계 | 과제 | 평가 기준 |
|---|---|---|
| 1~4 | 단어 · 짧은 문장 따라 읽기, 질문에 한 문장 답하기 | 목표 문장 일치율 |
| 5~8 | 대화 역할극(가게, 학교, 길 묻기), 3~4문장 답변 | 일치율 + 답변 적절성 |
| 9~12 | 주제 발표 1~2분, 의견 말하기, 후속 질문 답변 | 유창성(단어 수 · 멈춤) + 내용 + 문법 |

### 3.4 어휘와 복습

어휘는 교육부 교육과정 기본 어휘(초등 약 800단어, 중학교까지 누적 약 1,800단어)를 뼈대로 단계 밴드에 나눠 둔다. 각 트랙은 자기 단계 이하의 밴드에서 단어를 뽑는다. 유닛 생성 때 유닛 어휘 30개를 수업마다 새 단어 3~4개씩 배분하고, 이전 수업의 단어를 지문과 과제에 다시 쓰도록 계획한다.

세 트랙에서 만난 단어는 모두 한 단어장에 들어간다. 복습은 홈 화면에서 트랙과 상관없이 2분 분량의 플래시카드로 하고, 간격 반복 규칙으로 다음 복습일을 정한다. "안다" 상태는 서로 다른 날의 복습에서 3회 연속 정답이다.

### 3.5 동기 요소

세션마다 별 1~3개, 트랙마다 연속 학습 일수, 유닛 통과마다 배지를 준다. 두 달 동안 보상이 없는 상황을 피하기 위한 장치다. 부모 화면에서 아이의 관심 주제(동물, 게임, 우주 등)를 고르면 수업 생성에 반영한다. 별은 아바타 꾸미기에 쓰고, 부모가 실물 보상(예: 별 50개에 원하는 간식)을 등록해 두면 홈에 목표로 보인다. 그날 아이가 만든 문장 하나를 '오늘의 한 문장'으로 홈에 붙여 두어 아웃풋이 매일 하나씩 쌓이는 것을 보여 준다(리얼 아카데미의 1일 1아웃풋 참고, docs/research/2026-10-15-real-academy.md).

## 4. 화면

아이용 화면은 한 화면에 행동 하나, 큰 글자와 큰 버튼, 안내는 한국어라는 원칙으로 만든다. 시각 방향은 포스트잇 보드다(요청자 결정 2026-10-15). 코르크판 바탕에 종이 띠와 포스트잇(노랑 읽기, 하늘 쓰기, 분홍 말하기)으로 구성하고, 글꼴은 제목 Jua, 본문 Gowun Dodum, 영어 Fredoka 다. 목업은 https://claude.ai/artifact/BaG1A1Ewst9AzMLKHD4Zp2 에 있다. 세션 진행 상태는 단계마다 즉시 저장해서 앱을 닫았다 열어도 하던 곳에서 이어진다.

| 화면 | 내용 | 차수 |
|---|---|---|
| 홈 | 트랙 카드 3개(단계, 유닛 진행 5칸, 연속 일수, 오늘 완료 표시). 복습할 단어가 있으면 "복습 2분" 버튼. 구석에 부모 메뉴. 2차에 '오늘의 한 문장' 포스트잇과 실물 보상 목표를 더한다 | 1차 |
| 읽기 세션 | 3.3 절의 읽기 순서 | 1차 |
| 쓰기 세션 | 3.3 절의 단계별 순서. 1~3단계는 단어 카드 · 글자 타일을 누르거나 끌어 놓는 화면, 4~5단계는 문장 틀과 단어 상자, 6단계부터 자유 입력란. 확인은 같은 화면에, 첨삭은 다음 단계에 표시 | 1차 |
| 말하기 세션 | 3.3 절의 말하기 순서. 녹음 버튼, 인식 결과와 목표 문장의 차이를 강조 표시 | 1차 |
| 세션 결과 | 별, 오늘 얻은 단어, 유닛 진행 칸 증가, 배지 획득 축하 | 1차 |
| 복습 | 플래시카드, "알아요 · 몰라요" 자기 평가 | 2차 |
| 단계 평가 · 배치 평가 | 유닛 5개 통과 시 홈 카드에 "평가 보기"가 열림. 배치 평가는 첫 실행 때. 결과 화면에서 영역별 점수, 틀린 문항과 정답, 추천 단계를 바로 보여 준다 | 2차 |
| 부모 화면 | PIN 진입. 트랙별 진도, 최근 기록(쓴 글, 말한 내용), 단계 · 유닛 조정, 설정값, 다음 유닛 미리보기와 재생성, AI 사용량, 학습 지도(배운 문법 요소와 어휘 누적, 취약점), 이번 주 요약, 실물 보상 등록. 3차에 유닛 연습지 PDF 내려받기 | 2차 |
| 프로필 선택 | 첫 화면에서 아이 고르기 | 3차 |

## 5. 데이터

Postgres 테이블 13개다. 단계 규격, 유닛 규격, 어휘, 배치 평가 문항은 저장소 안의 시드 데이터로 관리하고 DB 에 넣는다.

| 테이블 | 역할 |
|---|---|
| profiles | 아이 이름, 아바타, 관심 주제 |
| level_specs | 트랙 × 단계 36행. CEFR, can-do 문장, 지문 길이 · 문제 수 · 분량 같은 규격 JSON |
| unit_specs | 단계당 5개, 180행. 문법 초점, 주제, 유닛 어휘 목록 |
| vocab | 기본 어휘 약 1,800개. 단어, 뜻, 예문, 단계 밴드 |
| profile_tracks | 프로필 × 트랙. 현재 단계 · 유닛, 연속 일수, 마지막 학습일 |
| sessions | 세션 1회. 트랙 · 단계 · 유닛, 생성된 수업 내용 JSON, 상태(준비 · 진행 · 완료), 점수 |
| attempts | 세션 안의 단계별 시도. 입력(답, 글, 인식된 말), AI 피드백 JSON, 점수 |
| recordings | 말하기 녹음 파일 경로와 길이. Storage 에 두고 90일 뒤 삭제 |
| vocab_progress | 프로필 × 단어. 다음 복습일, 연속 정답 수, 출처 트랙 |
| unit_progress | 프로필 × 트랙 × 단계 × 유닛. 수업 횟수, 최근 5회 점수, 어휘 숙달률, 통과 시각 |
| level_tests | 단계 평가와 배치 평가 기록. 문항, 답, 점수, 통과 여부 |
| settings | 설정값(12절)과 부모 PIN |
| ai_calls | AI 호출 기록. 목적, 모델, 토큰, 비용, 지연 시간 |

유닛 통과 판정, 단계 승급 판정, 간격 반복 스케줄, 생성 결과 검증, 따라 말하기 일치율 계산은 DB 에 의존하지 않는 순수 함수로 분리한다.

## 6. AI 호출

### 6.1 공통 규칙

모든 호출은 서버 액션에서만 일어나고 API 키는 서버에만 둔다. 모델은 Anthropic 공식 SDK 로 호출하는 Opus 5.5(`claude-opus-5-5`)이고, 응답은 Zod 스키마로 정의한 JSON 규격(structured outputs, `output_config.format`)으로 받는다. 시스템 프롬프트는 고정부(트랙 규칙, 아동용 내용 기준, 설명은 한국어)와 가변부(단계 can-do, 유닛 어휘와 문법, 관심 주제)로 나누고 고정부에 프롬프트 캐시를 건다. 서버 측 fallback(`fallbacks: "default"`)을 켜고, 안전 분류기 거절(`stop_reason: "refusal"`)은 생성 실패로 처리한다. 호출마다 토큰 · 비용 · 지연 시간을 ai_calls 에 기록하고, 프로필마다 하루 호출 상한을 둔다.

### 6.2 호출 목록

| 호출 | 입력 | 출력 규격 | 시점 |
|---|---|---|---|
| 유닛 수업 생성 | 트랙, 단계 규격, 유닛 규격, 관심 주제, 직전 유닛의 주제 목록(중복 회피) | 수업 12회분. 읽기는 지문 · 목표 단어 · 문제(보기 4개, 정답, 한국어 해설), 쓰기는 1~3단계에서 단어 · 어구 · 문장 묶음과 정답, 4단계부터 과제 · 예시 · 힌트 · 채점 기준, 말하기는 따라 말할 문장 · 질문 · 역할극 시나리오 | 유닛 진입 시 다음 유닛을 Batch API 로 생성 |
| 보강 수업 생성 | 위와 같음 + 약한 어휘 · 문법 | 수업 1회분 | 유닛 통과 기준에 못 미칠 때 실시간 |
| 쓰기 확인(4~5단계) | 과제, 아이의 문장, 단계 | 칭찬 한 줄, 고칠 곳 최대 1개(원문 · 수정 · 한 문장 이유) | 제출 직후 |
| 쓰기 첨삭(6단계부터) | 과제, 아이의 글, 단계 | 칭찬 1개, 교정 최대 2개(원문 · 수정 · 이유), 모범 답안, 루브릭 점수 3개, 종합 점수 | 제출 직후, 스트리밍 |
| 말하기 평가 | 질문 또는 목표 문장, 인식된 텍스트, 단계 | 내용 피드백, 문법 지적 최대 1개, 점수 | 답변 직후 |
| 역할극 | 시나리오, 대화 기록 | 상대역 다음 대사(단계 어휘 안에서), 종료 여부 | 턴마다 |
| 생각 꺼내기 대화 | 과제, 대화 기록, 단계 | 다음 질문(한국어), 아이의 답에서 끌어낸 생각 요약, 종료 여부 | 쓰기 6단계부터, 턴마다, 최대 3턴 |
| 단계 평가 생성 | 트랙, 단계, 유닛 5개 규격 | 20문항 | 유닛 4 통과 시 |

쓰기 1~3단계의 고르기 · 받아쓰기 · 조립과 읽기 문제는 AI 없이 앱이 정답과 비교해 채점한다. 따라 말하기의 일치율도 AI 없이 단어 단위 정렬로 계산한다.

### 6.3 사전 생성 일정

| 시점 | 하는 일 |
|---|---|
| 첫 실행, 배치 평가 완료, 부모의 단계 조정 | 현재 유닛과 다음 유닛의 수업을 생성한다 |
| 유닛 N 진입 | 유닛 N+1 의 수업 12회분을 Batch API 로 생성한다. 1시간 안에 끝난다 |
| 유닛 4 통과 | 그 단계의 단계 평가 20문항을 생성한다 |
| 다음 유닛이 준비되지 않은 채 필요해질 때 | 수업 1회분을 실시간 생성하고, 유닛 전체 생성을 다시 건다 |

항상 현재 유닛의 잔여분과 다음 유닛 전체가 준비된 상태를 유지하므로 2~3주 분량의 버퍼가 생긴다. 부모 화면에서 다음 유닛의 수업을 미리 보고 재생성시킬 수 있다.

### 6.4 생성 결과 검증

생성된 수업은 저장 전에 검증한다. 지문 길이와 문장 수가 단계 규격 범위 안인지, 유닛 어휘가 수업마다 배정된 대로 들어갔는지, 정답 번호가 보기 범위 안인지, 금지 내용(폭력, 개인 정보 요구 등)이 없는지 확인한다. 실패하면 최대 2회 다시 생성하고, 그래도 실패하면 그 수업만 비워 두고 부모 화면에 표시한다.

## 7. 음성 처리

음성 인식과 읽어 주기는 브라우저 Web Speech API 를 쓴다. 비용이 없고 Chrome · Edge · Safari 에서 동작하며 Firefox 는 지원하지 않는다. 품질이 부족해지면 교체할 수 있도록 인식과 합성을 각각 인터페이스 하나 뒤에 둔다. 녹음은 Storage 에 저장하고 90일 뒤 삭제한다. 외부로 보내는 것은 인식된 텍스트뿐이다.
