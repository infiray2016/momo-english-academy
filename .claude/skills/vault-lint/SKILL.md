# 볼트 lint

## 자동 검사
```
python3 .claude/hooks/vault_check.py --lint --fix
python3 .claude/hooks/vault_check.py --report
```
첫 명령은 끊긴 링크 · 고아 쪽 · `sources` 없는 위키 쪽을 찍고 `위키/문서-관계.md` 의 두 교차표를 다시 만든다. 둘째는 log · 일지 · 이번 턴 변경 · 빚(미작성 일지) 상태표다.

## 손으로 하는 대조 (때에 따라)
| 때 | 하는 일 |
|---|---|
| 검토 회차가 끝났을 때 | 반영본 spec 과 제품 쪽(시스템-구성 · 데이터-모델 · AI-호출 · 수업-생성 · 사다리와-승급)을 절마다 대조해 낡은 문장을 고친다. 바뀐 숫자(단원 수업 수 · 예산 · 어휘 수치 · 교정 상한)를 먼저 본다 |
| 커밋했을 때 | `원자료/산출물/YYYY-MM-DD_산출물_저장소-포인터.md` 를 새로 만들고 승인 · 반영 판본 사본을 넣는다 |
| 세션 끝 | 자동 검사 두 개, 일지 작성 여부, 메모리 갱신 |
| 주 1회 | 충돌 · 미확정 절에서 요청자 결정으로 닫힌 것을 정리하고 결정-목록의 잠정 행을 확정으로 옮긴다 |

고친 뒤 `log.md` 에 `- YYYY-MM-DD · lint · <한 일>` 한 줄을 남긴다.
