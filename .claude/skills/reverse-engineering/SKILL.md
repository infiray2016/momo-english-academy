# 리버스 엔지니어링 (살펴보되 바꾸거나 복제하지 않기)

조사 원문은 `docs/research/2026-10-16-reverse-engineering.md`, 정리는 볼트 `위키/방법론/리버스-엔지니어링.md`. 정의는 Chikofsky · Cross(1990)다. **대상의 구성 요소와 관계를 찾아 더 높은 추상으로 표현하는 일이고, 바꾸거나 복제하는 일이 아니다.**

## 선(법 · 윤리)
한다: 공개 자료 읽기, 요청자 기기 · 요청자 계정으로 정상 이용하며 보기, 분석용 소량 캡처(사실과 구조만 기록, 표현은 옮기지 않음), 우리 키 · 우리 기기로 우리가 쓰는 외부 API 와 브라우저 기능 관찰, 우리 코드 읽기 전용 분석.
하지 않는다: 프로그램 디컴파일 · 앱 분해, 보호 조치 우회(로그인 · 유료 벽 · 인증서 고정 · 라이선스 확인 · 난독화), 남의 서버에 자동 요청, 아이 · 타인 계정 사용, 남의 문장 · 그림 · 음원을 시드로 복사, 자동 접근을 막은 사이트 우회. 한국 저작권법 제101조의4 의 역분석 예외는 호환 목적뿐이라 경쟁 분석은 기댈 수 없다. 이 스킬은 법률 판단을 내리지 않는다.

## 절차
1. 묻는 것 정하기. 알고 싶은 것을 한 문장으로 쓰고 갈래(참고 서비스 분해 · 외부 API 관찰 · 코드에서 spec 되짚기 · 시드 분해) 하나를 고른다. 볼트 `index.md` 와 `docs/research/` 에 답이 이미 있으면 거기서 끝낸다.
2. 법 · 윤리 확인. 대상이 남의 서비스면 약관을 읽어 한 줄 적고 보호 조치와 개인정보를 확인한다. 위 '하지 않는다' 가운데 하나라도 걸리면 멈추고 요청자에게 알린다.
3. 가장 얕은 깊이부터. 공개 자료 → 직접 써 보기 → 소량 캡처 → 내 키 · 내 기기 관찰 → 코드 읽기 전용 분석 순서로 가고 답이 나오면 멈춘다.
4. 관찰 계획 쓰기. 질문 목록, 기대값(문서나 spec 이 말하는 것), 방법, 비밀값과 개인정보가 새는 길(HAR · 프록시 기록 · SDK debug 로그 · 캡처)과 막는 법. 시험 계정 · 시험 키 · 어른이 읽는 시험 문장만 쓴다.
5. 관찰하고 원자료 남기기. 날짜와 환경(기기 · 브라우저 · 모델 · 판)을 달고 비밀값을 가린 기록을 남긴다. 서브에이전트는 읽기 전용으로 시킨다. 웹 조사는 Sonnet high, 코드 · spec 대조는 analyst(Opus xhigh).
6. 기대와 관찰 맞대기. 같음 · 다름 · 못 봄으로 나눈다. 다름은 문서 오류 · 우리 가정 오류 · 환경 차이 가운데 어느 것인지 가린다. 모든 주장에 확인 정도(원문 · 검색 요약 · 추정)를 단다.
7. 결과 옮기기. 정본이 바뀌어야 하면 13절 결정 기록에 한 줄을 먼저 더한다(변경이 제품을 바꾸면 intent 부터). 조사는 `docs/research/`, 시험용 표본은 비밀값을 지운 고정 표본으로 올린다. 복원한 서술은 정본을 덮어쓰지 않고 어긋남 목록만 낸다. 이유(왜)의 정본은 13절이다.
8. 기록과 남은 질문. 볼트 원자료 사본과 기록 표시(`--mark-ingest`)를 하고 못 푼 질문은 '더 알아볼 것'에 적는다.

## REA MCP(선택, 요청자 2026-10-22)

참고 서비스가 웹 · JavaScript 앱이면 REA MCP(스킬 `reverse-engineer-anything`, `~/.claude.json` 사용자 수준 등록 — `npx -y rea-agents@6.7.0 mcp`)의 런타임 · 패키지 관찰 도구를 쓸 수 있다. 위 '선(법 · 윤리)' 그대로다 — 약관 안에서 관찰 · 기록만 하고, 디컴파일 · 보호 조치 우회 · 복제는 하지 않는다. 바이너리 분석 공급자(Ghidra · IDA · JADX)는 두지 않는다(환경 점검 'environment_healthy false' 는 그 뜻). 세션을 새로 열어야 MCP 도구가 보인다.

## 이 프로젝트의 쓸 곳(조사 제안 1~10)
| 단계 | 할 것 |
|---|---|
| Plan | 참고 서비스 직접 써 보기 질문표(아동 AI 대화의 글 표시 · 턴 수 · 통과 문턱 · 복습 양 · 부모 보고 · 가격), 가격 · 구성의 시간 변화(웹 보관소), 분해 노트 규칙 |
| Design | 음성 인식 이벤트 기록표(1-가 첫 작업 iPad 실기와 같은 관찰 페이지, Playwright 가짜 음성 대본으로 되살림), Anthropic 호출 관찰표(세 모델 × 호출 종류, 'AI 쉬는 중' 오류 응답, 구조화 출력 제약, 모델별 요청 제약 → 고정 표본) |
| Build · Review | 식별자 대조 스크립트(설정 키 · 테이블 · 스키마 · 라우트 ↔ 정본, 박힌 숫자 찾기), 서술 대조(analyst 가 코드에서 규칙을 뽑아 정본과 맞댐, 코드 위치 · 확신도), 순수 함수 동작 기록 테스트 |
| 시드 | 아이 눈 순회 체크 목록(인지 순회 네 질문 + 우리 질문 넷), 어휘 배정표를 CEFR-J 목록과 대조 |

## 지킬 것
- 용어는 영역 · 단계 · 단원 · 활동. 영어 개발 용어 직역 금지.
- 비밀값 · 아이 이름 · 아이 목소리를 기록 파일에 넣지 않는다. 기록 파일은 저장소에 올리지 않는다.
