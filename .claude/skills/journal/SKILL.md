# 개발 일지

파일: 볼트 `일지/YYYY-MM-DD.md`(오늘 날짜, KST). 틀은 볼트 `일지/README.md`. 프론트매터 `type: journal` · `kind: 일지` · `date` · `updated` · `status: current` · `tags: [프로젝트/momo-english-academy, 일지]`.

## 절 (같은 틀을 지킨다)
| 절 | 적는 것 |
|---|---|
| 오늘의 목표 | 세션 시작 때 요청자가 원한 것 |
| 한 일 | 시간순 표(때 · 일 · 결과물). 결과물은 저장소 경로나 볼트 쪽 링크 |
| 결정 | 요청자가 정한 것과 이유. 잠정이면 표시 |
| 막힌 것과 푼 방법 | 오류 · 되돌림 · 재시도를 숨기지 않는다 |
| 사람이 한 것 · AI 가 한 것 | 표. 브리프 · 프롬프트의 요지 |
| 교훈 | 다음에 다르게 할 것 |
| 다음 | 이어 할 일 |

## 순서
1. 오늘 파일이 있으면 절마다 행을 더한다(새 절을 만들지 않는다). 없으면 틀대로 새로 만든다.
2. `index.md` 일지 표에 줄이 없으면 더한다.
3. 커밋한 턴이면 커밋 해시를 '한 일' 표에 적는다.
4. 한 문장은 20자 안팎, 숫자는 표로, 군말 없이.
5. 볼트 `이어하기.md` 의 세 절도 같이 맞춘다. 일지는 '그날 이야기', 이어하기는 '지금 바로 이어 갈 것'이다.
