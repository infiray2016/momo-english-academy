# 볼트 ingest

볼트: `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/infiray/90_AI/프로젝트/momo-english-academy/`. 규칙 원문은 그 안의 `위키/방법론/지식저장소-운영.md`.

## 순서

0. 읽을 입력: 오늘 자동 대화 기록 `원자료/대화/YYYY-MM-DD_대화_세션기록.md`(훅이 턴마다 쓴 요청자 메시지 · 답 요지)와 `--report` 의 "미처리 원자료". 자동 기록은 원자료 그 자체이니 복사하지 않고, 거기서 결정 · 지시를 읽어 아래 분류대로 정리한다.
1. 이번 턴에 생긴 것을 종류별로 가른다.
   | 사건 | 원자료 | 파일 |
   |---|---|---|
   | 요청자 결정 · 지시 · 지적 | 대화 | 자동 기록(세션기록)이 원문이다. 결정은 위키 결정-목록과 닿는 쪽에, 지시의 결과는 log · 일지에 적는다 |
   | 검토자 · 편집자 보고 | 검토 | `원자료/검토/YYYY-MM-DD_검토_<회차>-<이름>.md` — 저장소 파일 사본 + 프론트매터 `source` |
   | 외부 조사 | 조사 | `원자료/조사/YYYY-MM-DD_조사_<대상>.md` |
   | intent · spec · plan 승인 · 회차 반영, 커밋 | 산출물 | `YYYY-MM-DD_산출물_<문서>-<판>.md` 사본 + 커밋 해시. 커밋했으면 `YYYY-MM-DD_산출물_저장소-포인터.md` 도 새로 |
   | 파이프라인 · 스크립트 실행 | 산출물 | 실행 기록(명령 · 결과 · 막힌 것) |
2. 원자료 파일을 쓴다. 프론트매터는 `type: raw` · `kind` · `date` · `source` · `status: immutable` · `tags`. 본문 첫 줄에 "원자료. 고치지 않는다. 출처: …".
3. 닿는 위키 쪽을 고른다. "만드는 것(제품) · 만드는 방식(방법론) · 쓰는 법(매뉴얼) · 보여 주는 것(소개) · 공통"으로 가른다. 쪽을 고치고 `sources` 와 본문 링크에 원자료 이름을 더한다. 기존 문장과 어긋나면 "충돌 · 미확정" 절에 둘 다 적는다. 새 개념이면 쪽을 만들고 분류 폴더에 둔다.
4. `index.md` 의 해당 줄과 원자료 표를 고친다.
5. `log.md` 에 `- YYYY-MM-DD · ingest · <원자료> → <바뀐 쪽>` 한 줄을 더한다. 이 줄이 없으면 Stop 훅이 턴을 막는다.
6. 볼트 `이어하기.md` 의 '지금 하던 것' · '다음 한 걸음' · '열린 질문'을 이번 턴 기준으로 고친다(세 절만, 자동 기록 절은 훅이 쓴다). 이것도 Stop 훅이 검사한다.
7. 검사: `python3 .claude/hooks/vault_check.py --lint --fix` (끊긴 링크 · 고아 · sources, 문서-관계 교차표 재생성).

## 지키는 것
- 원자료는 고치지 않는다. 틀린 것은 새 원자료로 더하고 위키에서 바로잡는다.
- 링크는 `[[쪽이름]]`(기본 이름). README · index · log 처럼 겹치는 이름만 전체 경로.
- 노트에 생 HTML 금지. 그림은 `그림/*.excalidraw.md` 를 `![[이름.excalidraw]]` 로.
- 문서 문체: 군말 없이, 콜론 제목 · 굵은 라벨 불릿 · 예고 문장 금지, 표를 적극.
