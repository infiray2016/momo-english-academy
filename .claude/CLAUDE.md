# momo-english-academy

모모 잉글리시 아카데미 — 초등 4학년부터 중학교 수준까지 집에서 혼자 배우는 영어 학습 웹 앱. 읽기 · 쓰기 · 말하기 · 회화 네 영역, 영역마다 12단계, 단계마다 단원 5개. 정본은 `specs/README.md` 의 표. 변경 단위마다 `intent/<날짜-슬러그>/` 폴더에 intent.md → spec.md(정본 델타) → plan.md 가 쌓인다(플레이북, 요청자 결정 2026-10-16).

## Commands
- 앱 코드는 1차 구현에서 생긴다. 뼈대가 생기면: `pnpm dev` · `pnpm lint`(Biome) · `pnpm test`(Vitest) · `pnpm e2e`(Playwright) · `pnpm build`
- 목업 캔버스: https://claude.ai/artifact/BaG1A1Ewst9AzMLKHD4Zp2 · 소개 영상 재생성: `docs/media/build-intro-demo-video.py`(스크래치패드 venv 의 Playwright · imageio-ffmpeg 필요, 15분)

## Conventions
- Next.js 16(App Router) · React 19 · TypeScript strict · Tailwind 4 · shadcn/ui · Supabase Postgres + Drizzle · Anthropic 공식 SDK(첨삭 `claude-opus-5-5`, 짧은 실시간 호출과 4단계부터의 회화 턴 `claude-sonnet-5-5`, 1~3단계 회화 턴 `claude-haiku-5-5`, structured outputs + Zod) · Web Speech API. 린트 · 포맷은 Biome 하나
- 용어는 영역(읽기 · 쓰기 · 말하기 · 회화) · 단계(1~12) · 단원(단계 안 5개) · 활동(세션 안의 차례). 문서와 화면에서 "트랙" · "유닛"을 쓰지 않고, 영어 개발 용어는 직역하지 않고 알맞은 우리말로 바꾼다(요청자 지시 2026-10-15). 코드 식별자는 영어(track · unit 허용)
- 아이 화면 문구는 한국어 해요체, 한 화면에 행동 하나, 큰 글자. 디자인은 포스트잇 보드(코르크 바탕 · 종이 띠 · 포스트잇 노랑 읽기 · 하늘 쓰기 · 분홍 말하기 · 연두 회화, 글꼴 Jua · Gowun Dodum · Fredoka)
- 피드백 규칙: 쓰기 1~3단계는 AI 없이 정답 비교, 4~5단계는 고칠 곳 최대 1개, 6~9단계 교정 최대 2개 · 10~12단계 3개 + 모범 답안(고쳐 쓰기 뒤). 말하기 1~3단계는 바른 답 들려주기만. 회화는 1단계부터 말로 하고 채점하지 않는다. 회화 수업은 토리가 선생님처럼 이끄는 10~20분 수업(인사 → 오늘 쓸 말 → 말해 보기(1~3단계) → 대화 15~25번 → 정리)이고 1~3단계 대화에서도 영어 문장을 미리 보이지 않는다. 토리가 바른 말로 되풀이하고 필요하면 짧게 설명하며, 5단계부터 대화 뒤 잘한 말 2 · 다음엔 이렇게 1(10단계부터 2). 읽기 문제 · 따라 말하기 일치율 · 말하기 1~2단계 질문 답 · 회화 단계 평가의 허용 답 일치율도 AI 없이 앱이 채점. 회화 단원 단어를 스스로 썼는지는 회화 턴 AI 가 기록하고 '안다'는 앱이 센다
- AI 호출은 서버 코드(서버 액션 · Route Handler)에서만, 키는 서버에만, 응답은 Zod 스키마로 검증. 모든 요청은 가족 접근 쿠키를 확인하고(없으면 401), 모든 테이블은 RLS 로 anon · authenticated 를 거부하며 DB 는 서버 Drizzle 로만 접근한다. 말하기 · 회화는 녹음하지 않는다. 수업 · 문제 · 평가 문항은 개발 때 미리 만들어 검증한 시드로 넣고, 앱은 실시간 호출(쓰기 확인 · 첨삭 · 말하기 평가 · 생각 꺼내기 · 회화 턴)과 'AI 쉬는 중'을 푸는 확인 호출(1토큰, 앱 진입 · 부모 화면 요청 때, 장애는 5 · 15 · 30분 간격, 콘솔 한도 · 계정 오류는 한 시간에 한 번)만 한다. 실시간 호출은 비용 · 횟수로 아이 진행을 끊지 않는다(알림과 매우 높은 안전 상한만). AI 를 못 쓰는 때는 'AI 쉬는 중' 상태 하나로 다룬다(spec 8절)
- 숫자(단계 구간별 단원 틀, 통과 80%, 하루 호출 알림 150 …)는 `settings` 설정값 — 코드에 고정하지 않는다
- 서브에이전트의 모델 · 추론 수준은 용도별 기본값(`~/.claude/CLAUDE.md` 공통 규칙: 설계 · 화면 검토자(design-reviewer)는 Fable · max(요청자 2026-10-22), 코드 검토자 · 분석가 · 규격 설계 Opus · xhigh, 반영 편집자 · 구현자 · 시드 본 생성 Opus · high, 웹 조사 Sonnet · high, 단순 작업 Sonnet · low)을 따르고 호출마다 `model` · `effort` 를 명시한다. 요청자가 따로 지정하면 그것을 따른다. 시드 본 생성 effort 는 spec S10 표본 비교 뒤 확정. 동시에 2~3개까지. 구현자와 검토자는 분리한다. fix 라운드는 3회까지, 넘으면 컨트롤러가 요청자에게. 설정 · 도구 성격의 작업은 가벼운 루프(계획자 없이 컨트롤러 브리프, 검토 high · 범위 한정, Minor 는 컨트롤러가 직접), 기능 작업만 전체 루프(요청자 2026-10-16, C52). 커밋은 요청자가 지시할 때
- 방법론 셋(요청자 2026-10-16): AI-Native SDLC(변경 단위 intent → spec → plan, 게이트마다 커밋)가 뼈대, 리버스 엔지니어링(`reverse-engineering` 스킬: 참고 서비스 직접 써 보기 · 쓰는 API · 브라우저 기능 관찰 · 코드 ↔ 정본 대조 · 시드 아이 눈 검토, 살펴보되 복제 · 우회 안 함), 그래프 엔지니어링(`graph-engineering` 스킬: AI 코딩 일(변경 단위 흐름 · 검토 루프 · 시드 생성 · 구현과 검토)을 점 · 선 · 공유 상태 · 게이트로 그리고, 길은 설계자가 정하며 검증은 선 위에 코드로 둔다. 수단은 스킬 + 훅 · 서브에이전트 · `Workflow`, 에이전트 팀 · LangGraph 류는 안 들임. 정본 참조 검사는 같은 스킬의 '자료 그래프' 절). 정리는 볼트 `위키/방법론/`
- 보조 스킬(요청자 2026-10-22, 별표 저장소 셋): 화면 설계 · 검토에 `ui-ux-pro-max` · `ui-styling`(uipro) · `design-taste-frontend`(taste-skill) — 정본 4절 · 포스트잇 보드가 우선, 스크립트는 안 돌림; 참고 서비스 분석에 REA MCP(`reverse-engineer-anything`, 사용자 수준 — 관찰만). uipro 의 `design-system` · `brand`(디자인 시스템이 기댐)는 두고 배너 · 슬라이드 · 종합 design(로고 · CIP 생성) 묶음만 뺐다(`uipro init --force` 하면 돌아옴, 요청자 2026-10-22 '디자인 시스템 묶음은 왜 뺐어')
- 꺼내 쓰기(query): 설계 · 결정 · 용어 질문 전에 볼트 `index.md` 를 읽고 닿는 쪽만 열어 출처를 단다. 전체를 읽지 않는다. 절차는 볼트 `지식저장소/위키/지식저장소-운영.md` "묻는 때"
- 기록(강제): 대화는 훅이 볼트에 자동 기록한다. 턴마다 옮길 결정 · 지시를 위키에 넣고 `python3 ~/.claude/hooks/vault_check.py --mark-ingest` 로 표시한다. 커밋 턴은 일지 · 이어하기까지. Stop 훅이 검사해 안 됐으면 턴을 끝내지 못한다. 규칙 원문은 볼트 `지식저장소/위키/지식저장소-운영.md`, 수치는 `--rules`, 상태표는 `--report`, 절차는 `/vault-ingest` · `/vault-lint` · `/journal` · `/wrap-up`. 비밀값 · 아이 이름은 대화에 적지 않는다

## Architecture
- 정본은 `specs/` 의 장 파일 열세 개(지도 `specs/README.md`, 절 번호는 그대로. 3절은 02-1 · 02-2 · 02-3 세 장). 13절(`specs/10-결정-기록.md`) 결정 기록이 승인 기록이다 — 설계를 바꾸려면 결정 기록에 한 줄을 먼저 더한다. 새 요구는 변경 단위 폴더 `intent/<날짜-슬러그>/` 의 intent.md → spec.md(델타) → 승인 뒤 정본 장 반영 → plan.md 참고 조사는 `docs/research/`
- 구현 차수: 1차(첫 운영 배포, 학습 규칙 전부) 1-가 뼈대 · 접근 제어 · 시드 규격 · 검증기 · 풀이 검사 · 적재 · 배치 평가 · 홈 · 수업 목록 · 읽기 · 쓰기 · 말하기 세션 · 회화 전부(요청자 2026-10-22 C85 로 1-나에서 당김 — P11b → P13 회화 → P12 → P11c) · 복습 · 숙달 판정 · 단원 통과 · 단계 평가 · 결과 → 1-나 부모 화면 일부 · 알림 · 신고와 정정 · 원문 삭제, 운영 배포는 1-나와 1~6단계 시드 뒤 한 번 → 2차 7~12단계 시드 · 재배치 평가 · 단원 미리보기 · 설정 화면 · 이번 주 요약 · 배지 · 부모 화면 나머지 → 3차 프로필 2~3개 · PWA · 연습지 PDF
- DB 의존 없는 순수 함수로 분리: 단원 통과 · 단계 승급 판정, 간격 반복 스케줄, 시드 검증기, 따라 말하기 일치율

## Things Claude gets wrong
- 초등 4학년에게 문장을 만들게 하지 않는다 — 쓰기 1~3단계는 고르기 · 베끼기 · 조립이다(2026-10-15 에 두 번 지적받고 단계표를 내렸다)
- 횟수로 단원을 통과시키거나 승급하지 않는다. 단원 통과는 어휘 숙달 80% + 최근 5회 80%(회화는 '말함' 80% + 끝낸 대화), 승급은 단계 평가다. 최소 수업 수 · 최소 학습일 수는 그보다 빨리 통과할 수 없다는 아래 한계일 뿐이다(단계 구간별 6~10회 · 4~7일, 쓰기 6단계 이상은 5~6회, 요청자 결정 2026-10-15 "무조건 8번은 이상하다")
- 1~3단계 회화에서 영어 문장을 보여 읽게 하지 않는다 — 대화 토막은 글 없이 힌트 버튼만이다(요청자 2026-10-15 '보이는 거 읽는 게 회화가 아니잖아')
- 설계 숫자를 화면 · 코드에 그대로 박지 않는다(설정값)
- 정지 화면에 줌(zoompan)을 걸면 영상이 떨린다 — 프레임을 한 장씩 렌더링한다
- 세션을 저장소 밖(`~/workspace`)에서 열면 `.claude/agents/` 도 볼트 기록 훅도 걸리지 않는다(2026-10-15 05시 검토에서 훅이 한 번도 돈 적이 없음을 발견) — `cd ~/workspace/momo-english-academy` 에서 시작한다
