# 모모 선생님 아바타 미리보기

미나(Mina)와 리오(Leo)를 실제 3D로 표시하는 독립 프로토타입입니다. 기존 VRoid Project 모델에 모모의 화면 디자인, 표정 전환, 미세 동작, 브라우저 음성 연결을 추가했습니다. 새로 모델링한 캐릭터는 아닙니다.

현재 앱과 작업 중인 worktree는 변경하지 않았습니다. 이 폴더만 별도 실행할 수 있습니다.

## 실행

Node.js 24 LTS를 권장합니다.

```sh
cd prototypes/teacher-avatar
npm ci
npm run dev
```

미리보기: <http://127.0.0.1:4317>

```sh
npm test
npm run build
# 개발 서버를 종료한 뒤 빌드 결과를 확인할 때
npm run preview
```

## 포함된 기능

- 갈색 단발의 미나와 후디 차림의 리오 선택
- 쉬기 / 말하기 / 듣기 / 칭찬 / 생각의 다섯 상태
- 눈 깜빡임, 시선, 숨쉬듯 작은 상체 움직임, 고개 기울이기와 끄덕이기
- 버튼으로 시작하는 영어 인사와 직접 입력한 문장 읽기, 영어 목소리 선택
- 음성 재생 시작·종료 이벤트에 연결된 말하기 상태와 영어 자막
- 음성 취소, 모델 전환 시 이전 재생 취소, 시작 실패·장시간 재생 타임아웃
- 움직임 줄이기 및 OS 접근성 설정 반영
- 데스크톱/모바일 레이아웃, 로딩 안내, 재시도

`듣기`는 표정 미리보기입니다. 마이크를 켜거나 녹음하지 않습니다. 실제 AI 대화나 학생 음성 인식은 연결하지 않았습니다.

## 앱에 연결할 때

`src/teacher-avatar.js`는 화면 UI와 분리된 렌더러입니다. `src/motion.js`가 상태별 동작을, `src/teachers.js`가 표시 이름과 모델 경로를 관리합니다.

```js
import { TeacherAvatar } from './teacher-avatar.js';

const avatar = new TeacherAvatar(canvas, {
  onContextLost: () => { /* 오류 UI 표시 */ },
});
await avatar.load('/models/mina.vrm');
avatar.setState('listening');
avatar.setReducedMotion(false);
// 음성이 실제 시작될 때 speaking, 종료·취소 시 idle로 연결
// 컴포넌트 unmount 시 반드시 호출
avatar.dispose();
```

캔버스 부모에 명시적인 크기가 필요합니다. 모델은 선택 시 로드하며 교체된 모델의 GPU 리소스를 해제합니다. 빠른 선택 변경으로 뒤늦게 도착한 로드 결과는 버립니다.

## 현재 한계와 확인 결과

2026-10-20 기준:

- `npm test`: 동작 규칙 테스트 5개 통과.
- `npm run build`: 성공. Three.js/VRM을 포함한 초기 JS 약 714 KB(압축 전)로 Vite의 500 KB 청크 경고가 있습니다.
- Chrome 브라우저에서 두 모델의 실제 렌더링, 다섯 상태 전환, 빠른 모델 선택, 움직임 줄이기를 확인했습니다.
- 390px 모바일 폭에서 가로 넘침 없이 레이아웃이 표시되는 것을 확인했습니다. 실제 iPad/Safari와 저사양 기기 성능은 미확인입니다.
- 확인한 렌더링 과정에서 브라우저 오류 로그는 없었습니다.
- **음성은 구현되어 있지만 실제 가청 출력 검증은 미완료입니다.** 자동 확인 환경에서 기본 목소리와 Samantha 선택 모두 재생이 즉시 종료되는 현상이 관찰됐고, 후속 진단 중 브라우저 연결이 끊겼습니다. 기기/브라우저의 영어 음성 설정과 실제 스피커 출력을 직접 확인해야 합니다. 원인을 확정하지 않았습니다.
- 입 움직임은 발화 중 주기적으로 움직이는 근사 애니메이션입니다. 단어·음소 단위 립싱크가 아닙니다. 소리 없는 `말하기` 버튼도 동작만 미리 보여 줍니다.
- 원본 VRM은 미나 약 17.1 MiB, 리오 약 18.1 MiB입니다. 한 번에 하나를 표시하지만 배포 전 텍스처/모델 경량화와 실기기 측정이 필요합니다.
- 모델은 로컬에서 제공하고 Google Fonts만 외부 요청합니다. 음성은 OS/브라우저가 제공하며 선택한 목소리에 따라 온라인 엔진이 사용될 수 있습니다.
- 본 앱 통합·배포는 하지 않았습니다.
