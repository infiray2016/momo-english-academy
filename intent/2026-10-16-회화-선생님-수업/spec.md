## 요약 (Summary)

정본에 원래 있던 것은 회화 영역 자체와, 채점하지 않고 토리가 반응한다는 원칙(R2), 토리의 대답은 모든 단계에서 실시간 AI 호출이라는 원칙(R3, 1~3단계 Haiku · 4단계부터 Sonnet)이다. 이 변경으로 회화 수업은 토리가 원어민 선생님처럼 이끄는 인사 → 오늘 쓸 말 → 말해 보기(1~3단계) → 대화 → 정리 다섯 토막이 되었고, 대화 토막은 어느 단계에서도 영어 문장을 미리 보이지 않는다(T2 · T4). 목표 턴은 3~8 에서 15 · 20 · 25 로, 한 수업은 약 10 · 15 · 20분으로 늘었고(T3), 1단계는 토리가 답 두 개를 소리로 들려주며, 1~2단계 막힘은 '힌트' 두 단(한국어 뜻 → 영어 문장)으로 풀고, 정리 토막은 AI 를 기다리지 않고 앱이 오늘 쓴 말을 되짚는다.

## 설계 (Design)

### 화면

| 정본 절 | 바뀐 것 |
|---|---|
| 4절 회화 세션 · 토막 | 한 화면에 한 토막씩 보인다. 오늘 쓸 말은 단어 · 한국어 뜻 · 예문 카드와 말하기 버튼 하나로 따라 말하고, 결과 말 뒤 ui.auto_next_seconds 에 넘어간다. 말해 보기(1~3단계)는 예문 카드 한 장씩이다. 첫 바퀴는 영어와 뜻, 둘째 바퀴는 뜻만 보이고, 둘째 바퀴에서 맞지 않으면 영어를 보이고 들려준다. 정리는 앱이 만든 되짚을 말을 토리 말풍선으로 읽어 주고 1~3단계는 문장마다 따라 말한다 |
| 4절 회화 세션 · 대화 | 아이 차례에 영어 문장이 없다. 큰 말하기 버튼 옆에 작은 '힌트' · '잘 모르겠어요'를 둔다. '힌트'는 누를 때마다 한 단씩 열리고 1~3단계 영어 문장 단에 듣기 버튼이 붙는다. 1단계 처음 묻는 턴과 인사 턴은 답 두 개를 소리로 들려주고 글 없는 듣기 버튼 ①②만 둔다. 1~3단계 그림 턴은 그림을 말풍선 옆에 크게 보인다. 1~3단계는 인식 글이 연 힌트나 들려준 답과 맞으면 확인 없이 보낸다. 위 띠는 '말 주고받기 n / 목표 턴'이고 목표 턴 뒤에는 '다 했어요! 더 이야기하기 n / talk.more_talk_round_turns'다 |
| 4절 회화 마무리 | 끝인사는 정리 토막에서 한 번만 하고 첫 장에 쓰지 않는다. 1~3단계는 둘째 장을 건너뛴다. 5단계부터 둘째 장은 끝맺음 턴이 올 때까지 기다림 표시를 둔다 |
| 4절 단계 평가 | 회화는 10턴 평가 대화 한 장씩 두 세션이다. 평가 턴의 한국어 뜻은 '내가 할 말' 이름표와 함께 보인다. '힌트'를 한 번 누르면 영어 틀이 열리고 버튼 이름이 '문장 다 보기'로 바뀐다 |
| 11절 목업 | B_Talk1 · B_Talk5 · B_TalkEnd 를 고치고, 회화 1~3단계 말하기 입력 · 말해 보기 토막 · 정리 토막 · 그림 턴을 새로 그린다. 1-가 시드 확정 때 한다 |

### AI 호출 · 규격

| 정본 절 | 바뀐 것 |
|---|---|
| 6.1 회화 턴 | 모델 · effort · 생각 단계는 변경 없음. 고정부를 공통 규칙(한마디 반응 · 바른 말 되풀이 · 구체적인 칭찬 · 재촉하지 않기)과 구간 규칙으로 나눴다. 4단계부터는 선생님처럼 이끈다. 반응 뒤 다음 질문을 하고, 오늘 쓸 말을 쓰게 묻고, 짧은 답은 세 턴에 한 번까지 문장으로 다시 묻고, 이어 묻는 질문을 세 턴에 하나 이상 한다. 1~3단계 tori_en 에는 반응과 짧은 연결 말만 쓴다. 턴 사용자 메시지에 토막 · 들은 도움 · '모름' 차례를 늘 넣는다 |
| 6.2 회화 턴 · 끝맺음 턴 | 입력에 토막(인사 · 인사 끝 · 대화 · 더 이야기하기)과 들은 도움(답 두 개 · 답 예시)을 더했다. 출력에 4단계부터 카드 질문 번호, 4~9단계 다음 턴 한국어 뜻 힌트 필드, 막힘으로 볼 말을 더했다. 판정 필드는 없다. 끝맺음 턴은 '그만하기' 때 응답 뒤에서 부르고(ai.timeout_seconds.feedback · ai.max_tokens.talk_closing), 되짚을 말을 내지 않는다 |
| 6.3 회화 카드 | 인사와 인사 턴 수, 오늘 쓸 말, 1~3단계 말해 보기 예문, 대화 첫 질문, 정리 대사(1~4단계 뜻 함께), 끝인사를 둔다. 1~3단계는 턴마다 질문 · 노리는 단어 · 처음/다시 묻는 턴 · 한국어 뜻 힌트 · 영어 문장 힌트 · 답 예시를 두고, 1단계는 답 두 개, 3단계는 영어 틀, 그림 키를 더한다. 1~3단계 질문 수는 목표 턴과 같고 '더 이야기할 거리'는 5턴이다. 4단계부터는 번호 붙인 카드 질문 목록을 둔다. 카드 수 2,010 은 그대로이고 단원 하나 생성은 40~80분으로 잡는다 |
| 6.3 · 6.4 평가 카드와 검사 | 회화 평가 카드는 단계마다 10턴 2장 × 3벌, 모두 72장(1~6단계 36장)이다. 검증기는 회화 카드의 질문 수, 처음 묻는 턴이 앞쪽 절반인지, 같은 글자 질문 두 번까지, 답 두 개 꼴, 3단계 영어 틀, 그림 키, 다시 묻는 턴 자리 수를 본다. 실시간 검사는 1~3단계 반응의 물음표 문장을 지운다 |
| 6.6 비용 | 회화 턴 입력 평균을 4,900 · 5,400 · 5,900 토큰으로 잡았다. 대화 하나는 1~3단계 약 0.011, 4~7단계 약 0.30, 8~12단계 약 0.40달러다. 캐시가 맞으면 0.004 · 0.10 · 0.12달러다. 월 알림 기준은 12달러이고, 4단계부터는 회화가 운영 비용의 4분의 3 이상이다 |

### 처리 규칙 · 판정

| 정본 절 | 바뀐 것 |
|---|---|
| 3.3 토막과 턴 | 목표 턴은 인사와 대화의 아이 턴이고, '모름' 턴과 막힘 턴은 세지 않는다. 목표 시간은 다섯 토막의 합이다. 토막 전환과 대화 첫 질문은 앱이 카드에서 이끌고 그때 AI 를 부르지 않는다. 오늘 쓸 말 · 말해 보기는 맞지 않아도 넘어간다. 보일 단어가 없는 수업은 둘 다 건너뛴다 |
| 3.3 대화와 막힘 | '잘 모르겠어요', 같은 질문의 no-speech 두 번, 막힘으로 볼 말은 '모름'이다. 토리는 답 예시를 말로 들려주고 같은 질문을 다시 묻는다. 두 번째 '모름'부터 힌트를 마지막 단까지 열고, talk.dontknow_max 번이면 다음 질문이다. 1~3단계 카드 질문이 모자라면 넘어간 질문, '더 이야기할 거리', AI 차례로 채운다. 처음 · 다시 묻는 턴은 앱이 아이 기록으로 정한다 |
| 3.3 정리와 멈춤 | 되짚을 말은 토리가 되풀이한 바른 문장 가운데 오늘 쓸 말이 든 것과 카드 정리 대사로, 오늘 쓸 말의 단어 수까지 만든다. 목표 턴 전 '홈'은 진행으로 남고 '그만하기'는 확인 뒤 중단이다 |
| 3.3 · 3.4 '말했다' | 오늘 쓸 말 · 말해 보기 · 정리의 따라 말하기는 세지 않는다. 답 두 개나 답 예시를 들은 턴은 힌트 종류 '영어'라서 세지 않는다 |
| 3.2 단원 통과 · 단계 평가 | 회화 단원 통과 조건(목표 턴까지 끝낸 정규 대화 수, '말함' 80% '안다')은 변경 없음. 관계 표 회화 행만 다시 셌다(1단계 정규 수업의 다시 묻는 턴 100~110 ≥ 48). 회화 단계 평가는 10턴 카드 두 장이다. 허용 답 일치율과 힌트 세 단 점수(S2)는 변경 없음. 평가 턴 no-speech 는 '모름'이 아니다 |
| 7 · 8절 | 읽어 주기에 카드 질문 · 답 예시 · 답 두 개('Or') · 되짚을 말 · 끝인사가 든다. 8단계부터 대화는 조용함(talk_long) · 말하기 버튼 · talk.max_answer_seconds 로 듣기를 끝낸다. 목표 턴 뒤 'AI 쉬는 중'은 정리 토막과 카드 끝인사로 닫는다. 4단계부터 끊긴 턴에는 카드 질문을 붙인다 |
