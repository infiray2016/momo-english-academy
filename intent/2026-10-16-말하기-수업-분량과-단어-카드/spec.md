## 요약 (Summary)

정본에 원래 있던 것은 말하기의 활동(따라 말하기 · 듣기 이해 · 질문 답 · 9단계부터 발표)과 세션 점수, '알아봄' · '씀' 두 상태의 복습 카드다. 이 변경으로 말하기는 회화와 따로 두는 영역으로 굳었고(T5), 분량이 약 1.5배가 되어 한 수업이 8~12분이 되었다(T6 · C9). 말하기 단원 단어는 소리만 듣고 뜻 고르기('알아봄')에 철자 타일 연습 한 번이 붙은 두 단계 카드로 복습하고, 단원 숙달은 '알아봄'으로 세어 철자 실력에 묶이지 않는다(T7 · C8 · C24).

## 설계 (Design)

### 화면

| 정본 절 | 바뀐 것 |
|---|---|
| 4절 말하기 세션 | 분량은 3.3 단계표다. 1~4단계 질문은 영어를 읽어 준 뒤 아래에 한국어 뜻(반말)을 보인다. 따라 말하기가 '잘 말했어요'면 ui.auto_next_seconds 뒤 저절로 넘어가고, 아니면 '한 번 더 말하기'(큰) · '다음'(작은)이다. 질문 답이 부분 · 다시이면 바른 답 문장을 들려주고 '같이 말해 볼까요'로 한 번 따라 말한 뒤 넘어간다. 6 · 8단계는 단어 그림 2~3장을 늘어놓는다. 9~12단계는 생각 화면 → 발표 → 피드백 한 문장 → 확인 질문이고, 점수는 부모 화면에만 있다 |
| 4절 복습 | 말하기 단원 단어의 카드는 글자 없이 소리만 듣고 뜻을 고르고, 맞히면 '이제 글자로 만들어 볼까요?'와 철자 타일을 한 번 한다. 둘째 단계는 단어 글자를 가리고 소리와 뜻만 보인다. 철자를 틀리면 바른 철자를 보이고 넘어간다. 첫 단계를 틀리면 정답만 보인다. 세션 끝에 다시 낸 카드는 첫 단계만 한다. 쓰기 단원 단어이기도 한 단어는 '씀'이 복습일이면 철자 타일을 먼저 하고, 맞으면 끝, 틀리면 바른 철자를 보인 뒤 '알아봄'이 복습일일 때만 뜻 고르기를 한다(C45). 결과 화면 '맞힌 카드'는 숙달에 든 단계가 맞은 카드 수다 |
| 11절 목업 | B_Speaking 의 분량(1단계 단어 5 · 문장 5, 듣기 3, 질문 4)과 결과 말 셋, B_Review 의 두 단계 카드와 '맞힌 카드 n장'을 고친다. 말하기 9~12단계 생각 화면을 새로 그린다. 1-가 시드 확정 때 한다 |

### AI 호출 · 규격

| 정본 절 | 바뀐 것 |
|---|---|
| 6.1 말하기 평가 | 3단계부터 부른다(C38). 모델 claude-sonnet-5-5 · effort low 는 변경 없음 |
| 6.2 말하기 평가 | 1~2단계 질문 답은 부르지 않는다. 9~12단계 발표는 내용 · 문법 점수, 피드백 한 문장, 확인 질문 3개를 낸다. 확인 질문 답은 같은 호출로 하나씩 채점한다. 확인 질문이 비거나 검사에 걸리면 시드의 예비 확인 질문을 쓴다. 평가의 발표 문항에는 확인 질문을 내지 않는다. 6 · 8단계 입력에는 시드의 영어 장면 설명을 넣는다 |
| 6.3 말하기 수업 | 따라 말할 단어 · 문장, 듣기 이해 문항, 질문(1~3단계 바른 답 문장, 1~2단계 허용 답 셋 이상, 1~4단계 한국어 뜻), 6 · 8단계 그림 키와 장면 설명, 9단계부터 발표 주제 · 쓸 말 세 개 · 예비 확인 질문 3개를 둔다. 수는 3.3 단계표를 따른다. 말하기 단원 하나는 25~50분으로 잡는다 |
| 6.4 검증 | '분량' 검사(문장 수 · 문제 수)가 3.3 단계표를 기준으로 쓰고, '그림' 검사가 그림 키 · 장면 설명을 본다. 말하기 수업만의 검사 행은 없다(우려 20) |
| 6.6 비용 | 말하기 평가는 수업마다 1~2단계 0회, 3단계 4회, 4~8단계 5회, 9~12단계 4회(발표 1 + 확인 질문 답 3)다. 한 번 약 0.011달러라 높은 단계 하루 1수업은 약 0.044달러다 |

### 처리 규칙 · 판정

| 정본 절 | 바뀐 것 |
|---|---|
| 3.1 영역 | 말하기는 듣고 이해하고 정해진 문장과 발표를 정확하게 말하는 힘이고 성적이 있다. 회화는 말을 주고받는 힘이고 대화를 채점하지 않는다(T5) |
| 3.2 단원 통과 · 시간 총량 | 말하기 단원 단어는 '알아봄'으로 센다(T7). 통과 조건(80% · 최근 5회 80%, 최소 수업 수 · 학습일은 아래 한계)은 변경 없음. 말하기 시간 총량은 약 135시간이다 |
| 3.3 말하기 세션 | 9단계부터 듣기 이해 뒤 생각 화면 → 발표 → 확인 질문 3개를 한다. 그 밖의 순서(새 단어 미리보기 → 따라 말하기 → 듣기 이해 → 질문 답)는 변경 없음. 질문은 세션 내용에만 두고 아이 이야기를 주고받는 질문은 회화에 두는 경계도 그대로다(T5) |
| 3.4 복습 카드 | 두 단계 카드의 첫 단계는 소리만 듣고 뜻을 고르며 '안다' 판정에 쓴다(C45). 겹치는 카드는 '씀'이 복습일이면 철자 단계를 먼저 하고 그 정오로 '씀'과 복습일인 '알아봄'을 센다(C45). 둘째 단계는 연습이라 연속 정답 · '안다'에 영향이 없다. 쓰기 알파벳 · 소리 단원을 통과하기 전에는 철자 연습을 건너뛴다. 겹치는 단어는 복습일이 된 상태만 세고, 두 상태로 숙달을 세는 영역 가운데 처음 만난 영역의 15장에 든다. 하루 복습은 약 7~8분으로 잡는다(두 단계 카드 12~15초) |
| 3.7 점수 | 식은 변경 없음. 1~2단계 질문 답은 맞음 1 · 다시 0 이고(C38), 9~12단계의 AI 몫은 발표와 확인 질문 답 셋의 점수 평균이다 |
| 8절 'AI 쉬는 중' | 1~2단계 세션은 질문 답까지 그대로 하고, 3~8단계는 따라 말하기 · 듣기만 하며, 9~12단계는 시작하지 않는다 |
