# Intent: iPad · iPhone 에서 선생님 목소리를 기기의 고품질 Apple 음성으로 고르기

작성자: 요청자(Claude 가 받아 적음) · 작성일: 2026-11-05 · 상태: review(보류 — 요청자 2026-11-05 15:0x, 13절 C199: Safari 에서 Siri 음성을 지정하기 어렵고 다른 기본 음성은 만족스럽지 않아 지금은 바꾸지 않음. 첫 프리뷰 뒤 외부 AI 음성과 함께 다시 판단)
출처: 요청자 결정 원문 `docs/research/2026-11-05-정할-것-셋-요청자-결정-원문.md`(2026-11-05 14:3x, 13절 C196 (2) · (5)) · 승인: 요청자, 2026-11-05(원문 "위 결정대로 진행해 주세요")

## 문제 (Problem)
읽어 주기는 Web Speech API 의 기기 기본 음성이라 품질이 낮다(정본 7절 7줄, 2026-10-15 잠정). 선생님 미나 · 리오는 같은 영어 음성에 높이(pitch)만 다르게 얹어 구분하고(7절 33줄 · 명단 voice.pitch 1.08 · 0.97, voice.prefer 는 비어 있음), 한국어 줄은 기기 기본 ko-KR 음성이다. iPad · iPhone 에는 Siri 처럼 자연스러운 Apple 음성이 있는데 앱이 고르지 않는다. 외부 AI 음성은 별도 변경 단위로 보류했으므로(C196 (2)), 비용 없이 지금 구조 안에서 품질을 올릴 길은 기기 음성 고르기다.

## 기대 결과 (Proposed outcome)
- iOS · iPadOS 에서 Safari 가 Siri 음성을 직접 쓸 수 있는지 확인된다. 안 되면 `speechSynthesis.getVoices()` 에 보이는 Apple 음성 가운데 가장 자연스러운 고품질 음성이 기본으로 골라진다.
- 영어와 한국어는 각 언어에 맞는 음성이고, 미나와 리오는 가능하면 서로 다른 고품질 음성이다(높이만 바꾸는 방식 개선). 쓸 수 있는 음성이 없으면 지금 기본 음성으로 대신한다.
- 특정 음성 이름을 코드에 고정하지 않고 기기가 주는 목록을 기준으로 고른다. 요청자가 iPad Safari 에서 음색 · 발음 · 영어 · 한국어 전환을 들어 확인한다.
- 재생 중단 · 다시 듣기 · 아이의 끼어들기 · 감시 타이머 · 기술 오류 복구 규칙(C53 · C166 R1 · C179 (2) · C184)은 그대로 작동한다. 외부 TTS 비용은 들지 않는다.
- 범위 밖: 외부 AI 음성(별도 변경 단위, 보류). 음성 인식. 평가의 음성 제공 여부 · 재생 횟수 · 도움 기록 규칙.

## 영향받는 사용자와 시스템 (Affected users and systems)
- 아이: 모든 영역의 읽어 주기(회화 선생님 말 · 한국어 줄 · 세 영역 수업 선생님 영어 · 읽기 지문 · 듣기 대본 · 평가 듣기 문항, C196 (1)).
- 시스템: 목소리 고르기 순수 함수(`src/core/teacher/voice.ts` 의 pickVoice · preferredVoice · voiceFor)와 음성 층(`src/lib/speech/browser.ts`), 선생님 명단 voice 칸(pitch · prefer), 정본 7절 33줄 · C130 (2)(8), 설정값(speech.*). 관찰 페이지(`src/app/dev/speech-probe`)나 별도 쪽으로 기기 목록을 본다.

## 제약 (Constraints)
- C196 (2) · (4) · (5), C102(iPad Safari · Chrome 둘 다) · C106 · C108 · C109(무음 모드 · 소리 통로 꼴 안 건드림) · C125 · C96(빠르기) · C130(명단 구조는 그대로, 칸 값만) · C166 R1 · C179 (2) · C184.

## 미결 사항 (Open questions)
1. (실측, 요청자 iPad) Safari 의 getVoices 목록에 어떤 Apple 음성이 보이는지, Siri 음성이 드는지, 고품질(premium · enhanced) 음성이 내려받기 없이 보이는지. 기기 목록 쪽을 만들어 요청자가 번호로 고른다.
2. (spec) '가장 자연스러운 고품질'을 기기 목록에서 고르는 규칙(음성 식별자 · 이름 표지의 우선순위)과 미나 · 리오를 다르게 고르는 규칙, 기기에 하나뿐일 때의 처리.
3. (spec) 한국어 줄 음성 고르기와 한국어 · 영어 전환의 자연스러움 확인 방법.
