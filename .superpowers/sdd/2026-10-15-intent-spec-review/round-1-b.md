## 결정이 필요한 것

요청자만 정할 수 있는 항목이다. 정해지면 13절 결정 기록에 먼저 한 줄을 더한다.

### D1. 앱 접근 제어 방식 (B1-01)
- 가. 가족 접근 코드: 기기를 처음 쓸 때 부모가 긴 코드를 넣으면 장기 httpOnly 쿠키를 준다. "회원 가입 없음" 원칙을 지키고 구현이 작다. 코드가 새면 바꾸고 기기마다 다시 넣어야 한다.
- 나. 부모 계정 하나(Supabase Auth 이메일 링크 로그인): 표준 방식이라 RLS 와 잘 맞고, 기기를 잃어버리면 세션을 끊을 수 있다. 1절 · intent 의 "회원 가입 범위 밖" 문구를 고쳐야 한다.
- 다. 플랫폼 앞단 차단(Cloudflare Access, Vercel 배포 보호 등): 앱 코드는 단순하지만 외부 서비스 · 요금제에 의존하고 태블릿에서 로그인 단계가 하나 더 생긴다.
- 검토자 권고: 가.

### D2. 1~2단계 그림 출처 (B1-03)
- 가. 공개 라이선스 그림 세트(이모지 · 아이콘 계열)를 어휘에 짝짓는다: 비용이 없고 바로 쓸 수 있다. 장면 그림 · 추상어는 표현하기 어렵다.
- 나. 어휘별 그림을 직접 고르거나 한 번 생성해 시드로 저장한다: 품질이 일정하다. 준비 시간과 라이선스 확인이 든다.
- 다. 수업마다 그림 생성 AI 를 부른다: 다양하지만 비용 · 지연 · 안전 검사가 더해지고, 13절의 범위(그림 생성은 3차 선택)를 바꿔야 한다.

- 가. 모든 호출에 Opus 5.5 를 유지하고 목표를 추정치(프로필당 월 약 6~17달러)에 맞춰 올린다: 품질과 구조가 단순하다.

- 다. 부모가 부모 화면에서 고른다: 유연하지만 화면과 설정이 늘어난다.

- 가. 영역당 하루 1회: 버퍼와 비용을 예측하기 쉽고 "하루 20분" 기대 결과와 맞다. 더 하고 싶은 아이를 막는다.

- 다. 무제한: 버퍼와 비용을 예측할 수 없다.

### D9. 단계 자동 하향 (B1-23)

### D10. 1차의 시작 단계 (B1-24)
- 가. 모든 영역을 1단계에서 시작한다: 가장 단순하고, 아이에게 쉬울 수 있다.
- 나. 요청자가 시드 설정으로 영역별 시작 단계를 정한다: 배치 평가 없이도 대략 맞출 수 있다.
- 다. 배치 평가를 1차로 당긴다: 1차 범위가 커진다.
- 검토자 권고: 나.

### D11. 점수 없는 세션을 판정에 넣는 방식 (B1-08)
- 가. 최근 N회 평균에서는 빼고 최소 횟수에는 넣는다: 마이크 문제로 진도가 막히지 않지만, 말하기 실력 확인 없이 통과할 여지가 생긴다.
- 나. 둘 다에서 뺀다: 판정은 엄격해지지만 마이크를 못 쓰는 날이 이어지면 말하기 진도가 멈춘다.
- 다. 영역마다 다르게 정한다(말하기만 엄격): 규칙과 테스트가 늘어난다.

## 참고: B1-02 비용 추정의 가정

검토자 추정이며 측정값이 아니다. 단가는 Opus 5.5 표준(입력 4 · 출력 20달러/100만 토큰), 배치는 50% 할인을 썼다.

| 항목 | 가정 | 월 비용(프로필 1개) |
|---|---|---|
| 실시간 호출 1회 | 입력 약 2,500토큰, 출력 약 1,000토큰(thinking 포함) → 약 0.03달러 | 하루 3회(낮은 단계) ~ 13회(쓰기 6+ · 말하기 5~8단계) × 30일 = 약 3~12달러 |
| 단원 수업 생성 1회(12회분, 배치) | 출력 3만~6만 토큰(thinking 포함) → 약 0.3~0.6달러 | 영역마다 8~10일에 한 단원 → 월 약 9회 = 약 3~5달러 |
| 합계 | 재생성 · 보강 · 단계 평가 생성 제외 | 약 6~17달러 |
| 하루 상한 60회를 매일 채울 때 | 60 × 0.03 × 30 | 약 54달러 |

## 근거로 확인한 외부 사실

- Claude API(claude-api 스킬 참고 자료, 2026-10-06 기준): Opus 5.5 는 입력 4 · 출력 20달러/100만 토큰, 캐시 읽기 0.20달러다. thinking 을 끌 수 없고 effort 기본값은 medium 이다. Batch API 는 50% 할인, 대부분 1시간 안 · 최대 24시간, 결과 29일 보관, 결과 상태는 succeeded · errored · canceled · expired 다. Opus 5.5 의 최소 캐시 길이는 512토큰, 기본 수명 5분, 쓰기 1.25배다. structured outputs 는 minimum · maximum · minLength · maxLength · 복잡한 배열 제약을 지원하지 않고, TypeScript SDK 가 이를 지운 뒤 클라이언트에서 검증한다. structured outputs 는 Batches · 스트리밍과 함께 쓸 수 있다. 서버 측 fallbacks 는 Batches API 에서 거부되고, 대상은 Opus 5 · Opus 4.8 이다. SDK 기본 타임아웃은 10분, 재시도는 2회다.
- MDN SpeechRecognition: Chrome 같은 브라우저는 서버 기반 인식 엔진을 써서 음성을 웹 서비스로 보낸다. processLocally 는 Chrome · Edge 139 이상(데스크톱)에서만 지원되고 Safari · iOS · Chrome Android 는 지원하지 않는다. Safari 는 webkit 접두사 판으로 지원한다.
- Vercel 문서(Cron 사용량 · 요금): Hobby 는 하루 1회까지만 실행되고 실행 시각은 지정한 시간 안(±59분)에서 정해진다.
- Supabase 가격표: 무료 프로젝트는 1주일 비활성 뒤 일시 정지되고 자동 백업은 포함되지 않는다.
- 용어: intent · spec 본문에 "트랙" · "유닛"은 13절 결정 기록 줄 말고는 쓰이지 않았다. `profile_tracks` · `unit.*` 는 코드 식별자라 허용 범위다.
