## 반영 규칙
- A · B 보고의 모든 지적(Critical · Important · Minor 전부, A 58 + B 35)을 반영한다. 각 지적의 "고치는 방법" 문장을 기본으로 쓰되, 위 요청자 결정과 부딪치면 결정을 따르고 변경 기록에 "요청자 결정 Rn 으로 대상 없음 · 바뀜"이라 적는다. 두 보고가 같은 곳을 다르게 고치라고 하면(예: B2-12 와 A2-03 의 말하기 배치 예비 문항 수 24 대 36, B2-07 과 A2-16 의 이름 틀 {NAME} 대 [이름]) 더 구체적인 쪽을 택하고 이유를 적는다.
- 결정이 필요한데 위 표에 없는 것은 편집자가 정하고 13절에 "잠정 — 요청자 확인 필요(검토 2회차)"로 한 줄씩 더한다. 변경 기록의 "편집자가 정한 값" 표에도 모은다.
- 문서 구조(1~15절)는 유지한다. 필요하면 절 안에 소절을 더한다.
- 용어 겹침을 없앤다. 수업 단위의 '다시 하기'는 그대로 두되, 다시 하기를 설명하는 말에서 "연습"을 빼고 "되풀이"로 쓴다(3.2 68줄 "다시 하기는 연습이다" → "다시 하기는 되풀이다", 4절 결과 화면 '연습했어요' → '다시 했어요'). '연습 수업'(단어 익히기 상태의 다른 주제 변형)은 그 이름을 유지한다. 활동 안의 재시도 버튼은 '한 번 더 …'로, 수업 단위만 '다시 하기'로(A2-U-18). 3.5 · 4절 · AC 의 '다시 말해 보기'는 '한 번 더 말해 보기'로 되돌린다.
- 목업은 고치지 않는다. 대신 4절 첫 문단에 "목업과 이 문서가 다르면 이 문서가 이긴다"(A2-U-17)를 넣고, 고칠 목업과 새로 그릴 목업(수업 목록 · 배치 평가 시작 화면 · 1차 부모 화면 · 회화 1~3단계 말하기 입력 화면)의 목록을 11절 1차 행의 시드 확정과 같은 자리에 적는다.
- 숫자는 설정값으로(12절). 아이 화면 글자 크기 기준(A2-U-16)은 4절에 숫자로 적는다.
- 용어: 영역 · 단계 · 단원 · 활동. "트랙" · "유닛" 금지. 영어 개발 용어를 직역하지 않고 뜻이 드러나는 우리말로 쓴다(예: '고아' · '다리' · '빚' 같은 말 금지). 새 이름을 지을 때 "무엇을 하는 것"이 보이게 짓는다. 글은 명확한 서술문, 콜론 제목 · 굵은 라벨 불릿 · 예고 문장 금지, 표를 적극 쓴다. 요청자가 "말을 알아듣기 힘들다"고 했으니 spec 의 새 문장은 짧게, 한 문장에 한 뜻으로.
- intent 는 해결책을 적지 않는다(B2-20). 성공 기준 (2)(A2-19) · (4)(R13) · 기대 결과의 하루 시간(R15)을 고치고, 미결 사항은 이번 편집 뒤에도 남는 잠정 결정(13절의 "잠정 — 요청자 확인 필요" 행) 목록으로 다시 쓴다.
- 13절 결정 기록: 요청자 결정 15행을 먼저 더하고(위 표), 뒤집힌 옛 결정 행(결정 8 별, 회화 입력 방식, Batch 생성, 단원 틀 균일)에는 "2026-10-15 뒤집음 → Rn" 표시를 붙인다. 편집자 잠정은 그 뒤에.
- 14절 · 15절: 새 규칙마다 AC 가 하나 이상 있게. 보고가 붙여 준 AC 문장을 쓴다.
- 끝나기 전에 spec 전체를 검색해 옛 전제가 남지 않았는지 확인한다: "보기를 누르", "단어 상자를 누르", "적절성", "턴 완수율", "미션 달성률", "재도전", "복습 별", "다시 말해 보기", "Batch", "연습이다", "하루 1회", "하루 한 번". 13절 기록 행 밖에 남은 것은 0이어야 한다.
