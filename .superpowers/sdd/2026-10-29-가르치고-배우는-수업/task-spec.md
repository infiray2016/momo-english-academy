## 델타에 꼭 담을 것
1. **3.3 세 영역 세션 차례**: 공통 흐름 여섯 자리(오늘 배울 것 → 보여 주기 → 같이 해 보기 → 혼자 해 보기 → [틀리면 '왜' → 같은 문제 다시(연습) → 다른 예시에서 스스로(기회)] → 되짚기)와 영역별 방법 자리(표본 참조). 쓰기 1~3단계 문단을 '문법 용어 없는 한국어 한 줄로 설명하고 카드 놓기로 익힌다'로, 말하기 · 읽기 문단도 같은 자리로. 1~3단계 '문장 만들기' 경계(C169 (3)): 쓰기 3단계 조립 · 말하기 짧은 문장 응답 유지, 그 위로 새로 강제하지 않음. 4~12단계는 같은 흐름을 쓰되 설명 깊이 · 같이 해 보기 꼴이 어떻게 달라지는지(6단계 이상 쓰기 첨삭 흐름과의 관계). 목표 시간 표(단계표)의 갱신 방식(설정값).
2. **가르치는 이**: 아이가 고른 회화 선생님이 세 영역을 맡는다 — 화면은 초상 + 말(C130), 고르기 전(정상 흐름에선 없음)의 꼴, 7절 읽어 주기 규칙 '회화 쪽만 선생님 목소리' → 세 영역 수업의 선생님 말도 고른 선생님 목소리(읽기 지문 · 문항 읽어 주기는 어느 목소리인지 정한다).
3. **4절 화면**: 자리마다 화면(한 화면 한 행동 · 큰 글자 · 해요체), 선생님 초상 자리, '왜' 한 줄 화면, 다른 예시 화면, 되짚기 화면, 결과의 '오늘 배운 말', 정본 밖 문구 표. 디자인 ② 토큰 위에 얹힌다는 것만 적고 모양은 UI · UX spec 에 맡긴다.
4. **6.3 수업 시드 규격**: 새 칸(영어 식별자 · 뜻 · 자리 · 필수 여부) — 오늘 배울 것 한 줄, 못 하던 것 → 스스로, 본보기(문장 · 뜻 · 한 줄 설명), 같이 해 보기 문항(앱이 채운 부분 · 아이 자리 · 반응), '왜' 한 줄(문항마다), 다른 예시 문항(혼자 문항마다 짝), 되짚기(배운 말 · 마무리 한 줄), 활동마다 연습 · 기회 표시와 닿는 목표 ID(평가 spec 2절 꼴). 영역별 방법 칸. **6.4 검증**: 길이 상한(설정값) · 문법 용어 금지 목록(3.6 메타 문장과 별개 — 아이 화면 금지어로) · 단어 범위 · 혼자 문항마다 다른 예시 짝 있음 · '왜' 있음 · 선생님 이름 없음 · 설명 시간 합 상한. 생성 브리프(`seed/prompts`) 규칙 변경. 이미 만든 1단계 시드는 다시 만든다(범위 · 차례는 plan — 3단계 단원 1 세 영역 → 1 · 4 · 5단계).
5. **평가 체계 잇기(C169 (7))**: 자리마다 연습 · 기회 · 도움 — 같이 해 보기 = 연습(도움), 혼자 = 기회(독립), 같은 문제 다시 = 연습, 다른 예시 = 기회(독립, 같은 핵심 능력), 되짚기 = 연습 아님(기록만). 평가 spec 3판 4절 표와 어긋나지 않게 참조로 쓰고, 어긋나는 데가 있으면 우려로 올린다(그쪽 fix 로).
