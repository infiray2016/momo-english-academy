- 어떻게: 홈 카드에는 `label` 을 넘기지 않아 안의 글이 이름이 되게 한다('시작!'은 이미 `aria-hidden`). 이름을 짧게 두려면 `aria-label` 은 두고 상태 줄(마이크 · 내 단계 찾기 · 오늘 완료)에 id 를 붙여 `aria-describedby` 로 잇는다. e2e 는 `data-home-card` 로 고르므로 시험은 바뀌지 않는다. 화면 검토와 겹치면 des-p10 판정을 따른다.

**M-4. AC-2a 첫 e2e 의 '배치 전은 배치 평가로 간다' 절은 차례 5 까지 비어 있다.**
- 무엇이: 시험 이름이 '(배치 전은 배치 평가)'를 말한다. 그러나 `PLACEMENT_OPEN = false` 라 배치 전 카드는 `aria-disabled` 만 단언한다(`home.spec.ts`:108-112). 가는 곳(`/<area>/placement` · 회화 `/speaking/placement`)은 시험에 없다.
- 왜: 차례 순서상 지금은 열 수 없어 결함은 아니다. 다만 spec-trace 는 이미 덮은 것으로 센다.
- 어떻게: 장부 :46 에 '차례 5 에서 상수를 켤 때 이 시험에 href 단언 · 눌러 들어가기를 더함'을 적어 둔다.
