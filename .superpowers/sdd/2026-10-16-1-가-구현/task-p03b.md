## 지킬 것(plan 값 1~13 그대로 + 컨트롤러 결정)
- 401 은 `unauthorized()`(authInterrupts, C55 (4)): proxy 는 쿠키 없는 페이지 GET · HEAD(next-action 없음 · /api 아님)를 `/access` 로 다시 쓰기만 하고, `/access` 페이지가 `hasValidAccess()` 면 `redirect("/")` 아니면 `unauthorized()`. 서버 액션 POST · `/api/` · 그 밖 메서드는 proxy 가 401(WWW-Authenticate 없음). `/access` · `/access/submit` · `/api/cron/` 은 넘긴다. 모든 서버 액션 · Route Handler 첫 문장 `await requireAccess()`(제출 끝점과 Cron 만 예외, 훑기 시험 허용 목록에 까닭).
- 해시 argon2id(`@node-rs/argon2` 기본값, C55 (5)), `ACCESS_CODE_MIN_LENGTH` 12 · `/^[A-Za-z0-9]+$/`, `ACCESS_IP_RETENTION_MS` 하루 — 둘은 이름 붙인 상수(C57, 보안 · 개인정보 고정 규칙). 쿠키 `momo_access` = `v1.<만료 초>.<nonce>.<HMAC-SHA256>`, HttpOnly · Lax · Path=/ · Max-Age = access.cookie_days · Secure 는 https 때만 · 연장 없음(C55 (6)). 열쇠는 `ACCESS_CODE_HASH` 에서 HKDF-SHA256(info 둘, 쿠키 · IP). `encodeAccessCodeHash` 는 base64url(`$` 없음).
- 제출은 Route Handler `POST /access/submit`(C55 (7)): 같은 출처(Origin = Host)만, Zod `{ code }`, 결과 ok 204 + Set-Cookie · wrong 401 · locked 429 + Retry-After · not_configured(또는 SettingMissingError) 503. 한 트랜잭션에서 하루 지난 IP 행 지우기 → 행 넣기(onConflictDoNothing) → FOR UPDATE → 잠금 확인 → 코드 확인 → 성공이면 행 삭제 · 실패면 failed_count · locked_until. 설정은 `getSettings` 로 한 번(양의 정수 규격). **질의 SQL 안에 now() · CURRENT_TIMESTAMP 를 쓰지 않는다 — 시각은 `now()` 한 시계 값을 매개변수로 넘긴다**(P3a 검토 메모).
- Cron: `/api/cron/` 접두와 `requireCron(request)`(`Bearer <CRON_SECRET>`, 길이 같을 때 timingSafeEqual, C55 (8)).
- 화면 문구는 4절 · C57 그대로: 제목 '부모님이 코드를 넣어 주세요', 이름표 '가족 접근 코드', 버튼 '들어가기', 틀림 '코드가 맞지 않아요. 다시 넣어 주세요', 잠김 '잠시 뒤에 다시 넣어 주세요'(남은 분 없음), 끊김 '인터넷이 끊겼어요. 연결되면 다시 해요', 그 밖 '지금은 들어갈 수 없어요. 잠시 뒤에 다시 해 주세요'. 한 화면 한 행동, 안내는 `role="status"` 한 줄, 글자 · 높이는 plan 값 7(text-xl 이상 · 버튼 text-2xl · min-h-14). 입력칸 속성은 값 8.
- `/dev/*` 도 쿠키를 요구한다(C57, NFR-5 그대로). 관찰 페이지를 proxy 에서 빼지 않는다.
- `scripts/access-code-hash.ts`(값 10)는 코드를 어디에도 출력하지 않고 해시 한 줄만, 종료 0 · 1 · 2. `scripts/check-data-api.ts`(값 11)는 순수 함수 + 직접 실행, 테이블 29 를 P3a 스키마에서 `getTableName` 으로, 분류 다섯, 키 값 · 응답 본문 출력 금지, 종료 0 · 1 · 2.
- e2e: `tests/e2e/access-cookie.ts` 의 `addAccessCookie(context, baseURL)` 는 `E2E_ACCESS_CODE_HASH` 로 토큰을 만들고 `src/core/access-token.ts` 를 상대 경로로 가져온다. `smoke.spec.ts` 셋은 증명 표 이름 글자 그대로.
- 시험 이름은 증명 표 그대로(AC-1a · AC-N5 접두 그대로, 그 밖 그대로). 숫자는 `tests/fixtures/settings.ts`(access.cookie_days · parent.pin_max_attempts · parent.lock_minutes)에서. 시각은 인자로 넘긴다.
- `src/proxy.ts` 는 `@/core/access-token` 과 `@/server/clock` 의 `now` 만 가져온다(공용 변경 6 이 막는다). `server-only` 가 proxy 묶음에서 빈 모듈로 바뀌는지는 `pnpm build` 가 증명한다(P3a 위험 8) — 깨지면 시계 모듈에서만 `server-only` 를 빼고 보고에 적는다(P3a 파일 변경 절).
