## 3. 지적

### Important

**I-1. `firstSentence` 가 따옴표 속 영어 문장에서 잘라 한국어 피드백을 잃는다.**
- 무엇이: common.ts:170~172 는 P4a `splitSentences`(영어 문장 자르기)로 첫 조각을 낸다. 한국어 피드백이 아이 문장을 인용하면 인용 끝의 `.'` 뒤에서 잘린다. 재현:
  ```
  firstSentence("'I like apples.' 라고 또박또박 잘 말했어요.")  => "'I like apples.'"
  firstSentence("\"I go to school.\" 처럼 완전한 문장으로 말했어요.") => "\"I go to school.\""
  firstSentence("I like dogs. 라고 말했어요.") => "I like dogs."
  ```
- 왜: 쓰이는 곳은 쓰기 확인 이유(writing.ts:175) · 말하기 질문 답 피드백(speaking.ts:165) · 발표 피드백(332) · 확인 질문 답 피드백(436)이다. 아이 화면에 한국어 피드백 대신 영어 인용만 남는다. 4단계 '부분'에서 모델이 틀린 문장을 인용하면 아이의 틀린 문장이 피드백 자리에 홀로 보인다. C63 (4) 는 '한국어 칸은 첫 문장으로 정규화'이고 6.2(50 · 52줄)는 '한국어 이유 한 문장' · '피드백 한 문장'이라, 정규화 뒤 한국어 문장이 남아야 한다. 고정부는 인용을 막지 않고, 시험에 인용 사례가 없다.
- 어떻게: 한국어 칸용 첫 문장은 한글이 든 조각까지 이어 붙인다(예: `splitSentences` 조각 가운데 처음으로 한글이 든 조각까지를 공백으로 이음, 한글이 없으면 첫 조각). normalize.test.ts 에 인용 사례 하나(말하기 피드백 · 쓰기 이유)를 더한다.

**I-2. 전화번호 앞 경계 `\b` 때문에 붙여 쓴 번호가 새고, 연락처 먼저 차례가 영어 이름 바로 뒤의 번호를 새게 한다(AC-N4).**
- 무엇이: mask.ts:25 의 `\b0\d{1,2}…` 는 앞 글자가 영문자 · 숫자 · 밑줄이면 맞지 않는다. mask.ts:157~163 은 연락처를 먼저 가린다(다르게 한 것 1). 재현:
  ```
  "Ganada010-1234-5678" => "{NAME}010-1234-5678"   (contacts 0)
  "call01012345678"     => "call01012345678"       (contacts 0)
  ```
  plan 값 2 차례(이름 먼저)였다면 첫 줄은 `{NAME}` 뒤 `}` 가 경계가 되어 가려진다. 둘째 줄은 어느 차례든 샌다.
- 왜: AC-N4(15절 154줄)는 '생각 꺼내기 · 회화 입력의 전화번호 형태가 AI 요청 본문에서 가려진다'이고, plan 값 2 는 '붙여 씀'도 전화번호 꼴로 적었다. plan 위험 3 은 '개인정보가 먼저다(지나침을 받아들인다)'다. 오타로 띄어쓰기를 빠뜨린 영어 글에서 번호가 그대로 나간다.
- 어떻게: 경계를 숫자 기준으로 바꾼다. 영어 이름 정규식과 같은 '앞 글자 잡아 되돌리기' 꼴로 `(^|[^0-9])(0\d{1,2}[-. ]?\d{3,4}[-. ]?\d{4})(?![0-9])` 를 쓰고 첫 묶음을 되돌려 넣는다. 그러면 전화번호는 차례와 무관해지고, 연락처 먼저 차례는 전자 우편 때문에 그대로 둔다. mask.test.ts:135~137 의 '1010-1234-5678 그대로'는 숫자 앞 경계라 그대로 통과한다. 위 두 줄을 시험에 더한다.

**I-3. 생각 꺼내기 검증이 '또는 마지막 턴'을 보지 않아, 마지막 턴에 다시 요청할 기회를 잃는다.**

C63 (4) 와 정할 것 가 (1) 의 길이 대상은 '영어 학습 글 칸(바른 표현 · 보기 · 수정 · 모범 답안 · 바른 답 · 확인 질문 · 단어 · 틀)'이고 원문은 없다. plan 값 5 의 출력 검사 칸이 원문을 (en)으로 적어 plan 안에서 어긋난 것을 구현이 값 5 쪽으로 따랐다. 높은 단계에서 아이가 상한보다 긴 문장을 쓰고 모델이 그 문장을 통째로 원문에 인용하면 맞는 교정이 버려진다. 원문은 금지어 · 연락처만 보게(예: CheckField 에 길이 검사 여부 칸) 하거나, 컨트롤러가 값 5 대로 둔다고 정한다.
