## 계획과 다르게 한 것

1. 생성기가 `.env.example` 을 만들지 않았다(16.4.2 `app-tw-empty` + 이 옵션 조합). plan 은 '생성기 견본을 통째로 바꿈'이라 했으나 결과는 같다. 새로 썼다.
2. shadcn 4.21.5 init 이 `clsx` · `tailwind-merge` 대신 `cn@0.4.0` 하나를 넣었고 `src/lib/utils.ts` 는 `export { cn } from "cn";` 이다. `cn` 은 npm 관리자 shadcn(m@shadcn.com), 저장소 github.com/shadcn-ui/cn, 설명 'Drop-in replacement for clsx + tailwind-merge' 임을 `npm view` 와 `node_modules/cn/package.json` 으로 확인했다. 그 밖에 `radix-ui` · `shadcn`(런타임 의존, `globals.css` 가 `shadcn/tailwind.css` 를 가져옴)도 넣었다. plan 의 예상 목록과 다르지만 init 결과 그대로 두었다.
3. shadcn init 이 의존을 `^` 범위로 넣고 `@types/node` 를 `^24.19.2` 로 바꿨다. plan '설치 판' 머리의 '모두 정확한 판으로 고정'에 맞춰 잠금 파일이 고른 판으로 고정했다(`pnpm install` 결과 'Already up to date', 잠금 파일 내용 바뀜 없음).
