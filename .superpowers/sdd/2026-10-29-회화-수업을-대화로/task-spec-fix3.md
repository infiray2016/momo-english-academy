# 브리프: 회화 수업 델타 spec fix 3 — 요청자 최종 승인(C188)의 보완 반영 → 4판 approved(규격 설계자 · Opus · xhigh, 2026-10-30 03:4x)

요청자가 3판을 최종 승인했다(13절 C188, 원문 `docs/research/2026-10-30-회화-spec-3판-요청자-검토-원문.md`). 가~자 전체 방향 승인이고, 정본 반영 전 AC-6 참여 완료 규칙 한 곳과 이월 문장 하나를 보완하라 했다(새 승인 절차 없이 반영). 유효 수행 턴 조건의 운영 변경은 불승인이다. 이 fix 3 으로 `intent/2026-10-29-회화-수업을-대화로/spec.md` 를 4판 approved 로 만들고 고침표 `fix3-changes.md` 를 같은 폴더에 쓴다.

## 고칠 것
1. **카드 완료는 참고 정보(요청자 1).** 설계 4 '충분한 참여' 목록의 (3) '카드가 준비한 기회를 다 다뤘다'를 충분한 참여의 근거에서 뺀다. 마무리 물음 문장(설계 4 · 설계 2 기회 알림 · 토막 표 '대화' · 화면 7 마무리 물음 행 · 설정 키 talk.reask_per_word 설명 · AC-6 (가))의 '카드 기회를 다 다루면 참고 턴 전이라도 앱이 마무리 물음을 붙인다'를 없앤다. 앱이 'Do you want to talk more?'를 자동으로 붙이는 때는 참고 턴에 닿은 턴뿐이다. 카드 기회를 다 다뤘다는 사실은 사용자 메시지의 참고 정보로 Claude 에게 주고, Claude 는 아이 말의 흐름이 닿으면 자연스러운 마무리를 제안할 수 있다(앱 고정 대사가 아니라 Claude 의 반응 안에서 — 그 제안에 아이가 끝내겠다고 하면 아래 2 의 '그만하기'와 같이 다룬다).
2. **아이의 종료 의사 예외(요청자 2 · 3).** 끝난 길 표의 '그 전의 그만하기 → 확인 쪽지 → 중단'을 바꾼다. 아이가 '그만하기'를 고르면 앱은 기록 사실로 '참여가 거의 없음'인지만 가른다. 참여가 거의 없음 = 대화 토막(인사 토막 뒤)에서 아이가 말로 한 턴(입력이 말이고 막힘이 아닌 턴)이 하나도 없음 — 예: 인사만 하고 바로 끝냄. 그 밖은 모두 자연스러운 끝으로 받아 확인 쪽지 없이 정리로 가고 참여 완료 · 별 1 이다(참고 턴 15 에서 말로 8턴 대화한 뒤 끝내길 원하면 카드 기회가 남아도 완료). 참여가 거의 없음일 때만 확인 쪽지(C34)를 묻고, 확인하면 중단 · 별 없음, 취소하면 대화를 잇는다. 이 기준은 '있음 · 없음' 사실이지 턴 수 할당량이 아니다 — 새 설정 숫자를 만들지 않는다. 진행 참고값(talk.participation_ratio 0.6)은 완료 · 중단 판단에 쓰지 않고 사용자 메시지의 참고 정보(남은 흐름을 가늠하는 값)로만 남긴다 — 설정 키 설명 · [승인 사] · 말 표 '진행 참고값' · 설계 4 참고값의 자리 · FR-4 · 원칙 대조 C34 행 · 화면 7 행 · 회화 마무리 행 · 멈추는 경우 표를 같은 뜻으로 고친다. 키를 없애는 쪽이 더 단순하면 없애도 되며, 그러면 12절 · 설정 키 표 · 문서 반영에서도 뺀다(고침표에 까닭을 적는다).
3. **충분한 참여 정의 정리.** 위 1 · 2 를 넣은 뒤 '충분한 참여'는 기록으로 검증 가능한 사실 셋으로 남는다: (1) 마무리 물음이 나올 때까지 대화했다 (2) 바닥선으로 앱이 끝을 정했다 (3) 아이가 끝내길 원했고 참여가 거의 없음이 아니다. 자연스러운 종료 셋(마무리 물음에 답함 · 바닥선 · 그만하기)과 짝을 맞춘다. 요구사항 FR-4 · 설계 0 표 · 말 표 '참여 완료' · fix 2 반영표의 요약 문장도 같은 뜻으로.
4. **AC-6 수용 테스트(요청자 4).** AC-6 을 다시 쓴다: (가) 참고 턴 15 표본에서 말로 8턴 의미 있게 대화한 뒤 카드 기회가 남은 채 '그만하기' → 확인 쪽지 없이 정리 · 완료 · 별 1, (나) 인사만 하고(대화 토막 말 턴 0) '그만하기' → 확인 쪽지, 확인하면 중단 · 별 없음, 취소하면 대화 이어짐, (다) 카드 기회를 참고 턴 전에 다 다룬 표본에서 앱이 마무리 물음을 자동으로 붙이지 않고(그 턴 AI 응답에 질문이 있어도 됨) Claude 의 제안은 허용, (라) 말 주고받기가 참고 턴에 닿으면 남은 카드 기회와 관계없이 마무리 물음이 나오고 그 턴 AI 응답에 질문이 없음, (마) 어느 표본에서도 앱이 참고 턴 · 진행 참고값 · 카드 기회를 채우려고 카드 자리를 만들거나 마무리 물음을 늦추거나 앞당기지 않음. 수용 기준 머리의 으뜸 원칙 증명 문장도 맞춘다.
5. **이월(요청자).** 이월 문단 (다)와 [승인 아] · 말 표 '이월' · FR-10 · AC-16 에 한 문장을 더한다: 독립 시도가 talk.carry_independent_min 에 닿아 후보에서 빠진 것은 '다시 연습할 후보가 아니다'일 뿐 학습 목표 달성(근거 상태 2 · 3, 평가 spec 4절)이 아니며, 운영 평가 판정과 혼동하지 않는다. AC-16 에 '목록에서 빠져도 그 목표의 근거 상태는 바뀌지 않는다' 단언을 더한다.
6. **운영 변경 불승인 명시.** 미결 '따로 승인받을 것' 문단을 '요청자 불승인(C188)'으로 고친다: 유효 수행 턴 조건(talk.valid_turns_ratio)을 3.2 최소 수업 수에 쓰는 운영 변경은 승인하지 않았고, 병행 검증 결과를 본 뒤 별도로 판단한다. [승인 라] · 설정 키 talk.valid_turns_ratio · 범위 밖 표 · 우려 5 · 문서 반영 3.2 · 9절도 같은 뜻인지 확인한다(이미 후보 셈이라 대부분 그대로일 것).
7. **승인 표시.** 머리: 상태 `approved(4판 · C188, 2026-10-30 03:4x)`, 승인 줄에 '요청자 최종 승인(C188) — 가~자 전부, 보완 반영 fix 3'. 가~자 아홉 머리 이름표를 '요청자 승인(C188)'(가 · 나 · 마 · 바는 'C181 · C188')로. 요약에 4판 문단 하나(C188 보완 요지), fix 3 반영표(요청자 보완 넷 + 이월 + 불승인 → 자리)를 fix 2 반영표 위에. 미결의 '요청자 승인 대상 아홉' 문단을 '모두 승인됨(C188)'으로 정리하고, 남는 미결(병행 검증 뒤 운영 변경 판단, 사용 시험 측정 항목 등)만 둔다. 읽는 법의 승인 표시 설명도 맞춘다.
