# fix 1 바뀐 자리: UI · UX 개선 델타 spec 1판 → 2판(C179 반영)

대상 `intent/2026-10-29-UI-UX-개선/spec.md` · 작성 2026-10-29 22:2x(규격 설계자) · 근거 13절 C179(요청자 22:1x, 원문 `docs/research/2026-10-29-UI-UX-spec-1판-요청자-승인-원문.md`), 그 앞 컨트롤러 결정 C178. 2판 상태는 approved(C179 반영)다. 편집자는 이 파일의 델타만 정본에 반영한다. 1판의 다른 R 행과 설계는 그대로다.

보완 넷과 함께 넣은 것: (1) 첫 사용 홈의 위 띠(연속 학습 일수 · 별 수)에도 뜻 없는 0 을 보이지 않는다. (2) 읽어 주기 감시로 넘어간 발화를 정상 재생과 가르고, 소리 자극 자리에서 들려주지 못했으면 다시 듣기와 안내를 두며, 그 문항 · 턴은 기술 오류로 적는다. (3) 회화 별은 회화 spec 의 참여 완료에 붙고 목표 턴 수는 조건이 아니다. (4) 수업 목록을 거쳐야 하는 경우는 복구 예외로 정하고 상태와 이어 하기 위치를 보존하며 e2e 가 그 경로를 잰다. 그리고 D-2 · D-6 은 관련 변경 단위가 끝날 때까지 미완료이고, 필수 e2e 는 실제 실행 결과를 확인해야 완료다.
